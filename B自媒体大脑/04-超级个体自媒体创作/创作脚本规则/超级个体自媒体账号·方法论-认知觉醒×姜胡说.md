# 🧬 超级个体自媒体账号 · 方法论（认知觉醒 × 姜胡说）

> **一句话**：用"人性"把人留下，用"医生的拆解"让人相信，用"我的真实账本"让人转发，用"交底"让人愿意看完 8 分钟。
>
> 这份文件管 **讲什么、怎么讲、讲给谁、发到哪**；逐条写稿的执行规则见 [[AI观点口播账号·爆款公式与写作风格]]。**道与术分开，不打架。**

---

## 🚦 写稿流程·七步（写稿先看这里）

> 本流程 = 本文件全文的压缩包。**七步走完，定位、母题、骨架、人格、合规、交付全部落到位。**
> 格式对齐 [[AI观点口播账号·爆款公式与写作风格]]「写稿流程·八步」，交付闸门对齐 [[视频号脚本风格系统]]「八、写稿自检清单」＋ [[视频号风控总表]]；去 AI 味走双引擎：sepia（review→refactor）→ humanizer-zh 词句扫描 → ai-detector 复核。
> **动笔顺序是倒着的**：先写 ② 判断 → 再写 ⑥ 金句 → 再写 ④ 开场 → 最后填 ⑤ 中间。判断和金句定了，骨头就定了。
> **口播姿态**：写出来的是"照着能说出口的话"，不是作文。坐着、站着、走路都行，镜头前像在跟一个人说话——不端、不装、不背稿。

### ⚖️ 四源分工（各管一层，不抢同一段）

| 谁 | 只管一件事 | 落在哪几步 | 不碰什么 |
|---|---|---|---|
| 蓝宝宝 | **情绪入口**——让人停下来 | ① 切口 · ④ 钩子 | 不管逻辑、不管结尾 |
| 姜胡说 | **逻辑结构**——让人听得懂 | ② 结论 · ⑤ 因果 | 不做情绪、不做姿态 |
| 大麦哥 | **关系姿态**——让人不防你 | ① 自曝 · ③ 选骨架 · ⑥ 留白 | 不抢钩子、不给指示 |
| 你 | **事实内容**——凭什么是我讲 | ① 母题 · ② 判断 · ⑤ 案例 | 不当老师、不装完美 |

**统则：一层一人，抢了就砍。** 一段里出现两个人在干同一件事，说明这段写重了。

**三条冲突，先定死，写作时不纠结**

1. **抢 3 秒 vs 慢开场** → 按骨架分。A 抢 3 秒，B 用自曝换 30 秒耐心，**一稿里不同时存在**。
2. **结论先行 vs 不给答案** → 给「判断」不给「指示」。说"我认为 X"，不说"你应该 X"。
3. **扇醒狠话 vs 不指责** → 狠话只对事不对人，且只用在 A 骨架。

```
① 定选题（一条只讲一件事）
   ├─【我】六母题选一：一人公司 / 专业变资产 / 普通人起号 / AI 真实边界 / 大健康人的出路 / 长期主义与心力
   ├─【我】靶子要能一句话指认：「必须招人才能做大」✅　「穷 vs 富」❌
   ├─【麦】挑一个自曝资产：我失败 / 难堪 / 答不上来的具体场景（不是成就）
   ├─【蓝】选一个情绪切口（欲望 / 恐惧 / 不甘）+ 记下他心里那句原话
   └─ 先排除三条反定位（1.2）：不做 AI 工具教程 / 不做成功学 / 不做招商
   检验：这条是「我干了什么」，还是「我凭什么让人停下」？只写后者。
        ↓
② 立判断（一句话定生死）
   ├─【姜】结论先行：先说结论，再说为什么，别倒着讲
   ├─【蓝】说病因不说道理：你不是 X，你是 Y
   ├─【我】判断 ≤15 字、能截图、只有我讲得了（删掉「我」就不成立）
   └─【麦】只给判断不给指示：说「我认为 X」，不说「你应该 X」；没做到的明说
   检验：把「我」删掉还成立吗？成立就重写。
        ↓
③ 搭骨架（先选 A 还是 B，再各写一句）
   ├─ A·90 秒说服版（认知型 / 方法型）→ 六段，见 5.1
   ├─ B·3–8 分钟交底版（身份型 / 心力型 / 转折故事）→ 七段，见 5.5
   ├─ B 骨架顺手定数量锚点：这条讲几件事（3 / 5 / 6 / 10），数字进标题
   ├─ 配比：身份型 20% / 认知型 40% / 方法型 40%；每 3 条方法型插 1 条身份或认知型
   └─ 只写逻辑，不查资料、不堆数据
   检验：骨架卡写完，一眼能看出走的是 A 还是 B 吗？
        ↓
④ 写开场（A：3 句 8 秒｜B：1 句自曝 30 秒）
   ├─ A 三句：钩子（八型选一）→ 判断直接甩出 → 留一个缺口，前三句不答
   ├─ B 一句：说一个具体行为，不解释、不寒暄、不铺垫
   └─ 三禁：不自我介绍 / 不说「今天给大家分享」 / 不交代背景
   检验：A 要让人「咯噔」一下；B 要让人想「这人没装」。
        ↓
⑤ 写中间（A：三层因果｜B：N 件事）
   ├─ A 三层：大家以为的原因 → 真正的原因 → 所以结果会怎样
   ├─ B 的每件走四步：场景 → 我以前以为 → 后来发现 → 一句人话
   ├─【我】案例必须挂事：我 / 学员 / 临床，不许空讲道理
   ├─【麦】每 3 个案例至少 1 个是「我搞砸了」，不是「我成功了」
   ├─【姜】三条活路（仅 A）：具体到打开什么、写什么、发给谁，不喊口号
   ├─【麦】留一处「我也不知道 / 到现在也没做到」（仅 B）
   └─ 每 30 秒一个钩子；埋 2 个转发原子；口语化（5.3）：说人话 / 短句 ≤25 字 / 数字和画面
   检验：删掉所有例子还站得住吗？站得住＝在讲道理，重写。
        ↓
⑥ 写结尾（先选重还是轻）
   ├─ A 重结尾：压缩总结（回到开头）→ 金句 → 真心话 → 狠话（对事不对人）→ 追更钩
   ├─ B 轻结尾：金句 → 一句「我也还在路上」→ 开放提问（问「你有没有过……」，不问「你怎么看」）
   ├─ 金句要能截图、能复述、从前面的事实里长出来
   └─ 不喊转发 / 不喊「赶紧行动」 / 不承诺结果 / 不硬转产品
   检验：最后一句落在我这个人身上，还是落在「赶紧行动」上？
        ↓
⑦ 过质检 + 交付（四道闸，不过不交付）
   ├─ 闸 A 查重 → 闸 B 平台风控 → 闸 C 内容九关 → 闸 C 收口·去AI味双引擎 → 闸 D 交付格式
   ├─ 去AI味顺序固定：sepia（review→refactor）→ humanizer-zh 词句扫描 → ai-detector 复核
   ├─ 三问：有 1 处示弱吗？有 1 个失败案例吗？金句离开视频还成立吗？
   └─ 输出：口播正文 + 发布三件套 + 标签 + 权威锚点 + 入库
```

### 🧰 我的独家素材池（写稿从这抓，别空讲道理）

- **身份线**：农村娃 → 奥赛班 → 三甲麻醉科近十年 → 26 岁奶茶店亏 30 万 → 2020 全职大健康 → 今天的 AI 营养师
- **做事线**：700 粉到 2 万（一个半月）／知识库从 0 搭起／个人信息 AI 化／AI 员工与 SOP／每天怎么用 AI 干活
- **认知线**：心力不足＝认知不足／一个人就是一家公司／专业变资产／信任是慢的，流量是快的
- **态度线**：利他极客／专业死磕／选对圈子／方向对就够／越挫越勇
- **现场线**：我正在做的四件事——知识整理、自媒体输出、团队复盘、业绩突破

> **用法**：每条稿至少抓 2 个，其中 1 个必须是身份线或做事线的具体场景。**只讲道理不挂事 = 不合格。**

### 🗡 蓝宝宝口诀速查（写稿时贴眼前）

| 用在哪 | 口诀 | 具体动作 |
|---|---|---|
| 选题 | 不是让所有人喜欢你，是让一部分人迅速认出你 | 每条只对一类人说，敢让另一类划走 |
| 开场 | 道理只能让人点头，人性才能让人停留 | 第一句讲他的处境，不讲普遍道理 |
| 开场 | 先用人性把人留下来，再用干货让人信你 | 前 15 秒不给方法，只给「这说的是我」 |
| 中段 | 技巧是刀，不是手 | 结构是刀，经历和判断才是手——每条必须挂事 |
| 表达 | 口播不是念稿子，口播是情绪表达 | 写成能演出来的话，不是能读出来的字 |
| 改造 | 你不是 X，你是 Y | 把「方法」改写成「病因」 |
| 收尾 | 点赞是给作品的，关注是给人的 | 最后一句落在「我这个人」，不落在「这条内容」 |
| 复盘 | 戳得多深、留得多稳、接得有多准 | 完播看「戳」、点赞看「留」、关注看「接」 |
| 心态 | 别自证，也别下场 | 不跟评论区吵架，只盯目标 |

**《认知觉醒》四条写稿纪律：**

1. **一条只改一个认知**——懂得百点，不如改变一点。
2. **一条只解一个焦虑**——焦虑＝想同时做很多事，又想立即看到效果。
3. **讲他跳一跳够得着的那一层**——匹配，不讲超越三步的东西。
4. **每条给一个「改变动作」**——道理是空头支票，改变才是真金白银。

### 🔄 转发原子（本号写稿必埋 · 不喊转发）

> 视频号最重的指标是转发。但**转发不是靠结尾喊出来的，是靠内容里埋的"原子"自己长出来的**。
> 依据：[[B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统|视频号脚本风格系统]] 铁律 B「转发三件套」——社交货币 / 关心型对象 / 转发包 ≥2。**145 用 4 条硬数据做到转发率 9.06%，同结构的 107 没有硬数据只有 4.84%——差 87%。**

**转发原子 = 观众能一句话转述出去的东西。** 转的人手里得有货，空手转不动。

| 原子 | 长什么样 | 我的例子 |
|---|---|---|
| **数字原子** | 一个具体、可引用的数 | 一个半月，700 粉到 2 万 |
| **账本原子** | 一笔能算的账、一次真实的亏 | 26 岁开奶茶店，亏掉 30 万 |
| **命名原子** | 给一个道理起个能被带走的词 | 「AI 员工」「心力不足＝认知不足」 |
| **比喻原子** | 一个能复述的结构比喻 | 一个人就是一家公司 |
| **分装原子** | 一张能截图的三步清单 | 「知识库三步：先收、再分、最后让 AI 读」 |

**埋法四条：**

1. **每条稿 ≥2 个原子**，少一个不交付。
2. **落在中段**（③④⑤ 段），不堆在结尾——结尾堆数据，完播率掉（依据：145 四段连排，完播第五批最低）。
3. **每个原子挂一个具体场景**，不挂场景的数字是冷数据，没人转。
4. **想清楚"谁会在什么处境下转"**，是为了定语气和立场——**但不写进台词**。

**判据**：把这条稿发给一个朋友，他会主动转给别人吗？没把握 = 原子不够，回 ⑤ 补。

### 🔒 ⑦ 质检闸门（交付前 · 不过不交付）

> 顺序固定，不能跳：**闸 A 查重 → 闸 B 平台风控 → 闸 C 内容九关 → 闸 C 收口·去AI味双引擎 → 闸 D 交付格式。**

#### 闸 B · 平台硬风控（一票否决 · 2026 现行口径）

> 依据：[[B自媒体大脑/01-视频号创作/创作脚本规则/视频号风控总表|视频号风控总表]]（含「三、违规解密 · 星光研习社提炼」＋「七、2026 关键新规」）＋ [[B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统|视频号脚本风格系统]] 铁律15 ＋ 0号闸门。

| # | 红线 | 本号具体口径 |
|:-:|---|---|
| 1 | **不承诺结果** | 不出现月入／涨粉多少／包会／保证起号／财富自由／风口／躺赚；只讲方法、结构、代价 |
| 2 | **不卖焦虑** | 讲"结构变了"，不讲"你完了""再不学就晚了" |
| 3 | **医生身份只在故事层** | ✅「我在医院那几年」「我坐在旁边，一句话没说」；❌「以我从医十年经验告诉你」「我在手术台见过，所以你要…」（信源层 = 账号级风险） |
| 4 | **不碰医疗** | 疾病／疗效／指标／调理／根治／治愈／降压／包治 一律清；本号不下健康结论 |
| 5 | **不站外引流** | 无微信号／二维码／手机号／绿泡泡／「私信我」「评论区留号」；只留平台内动作（关注／粉丝群／公众号） |
| 6 | **不用绝对化** | 最／第一／唯一／顶级／永久／100%／独家 → 改「更」「相对」「我一直在用」 |
| 7 | **不教具体平台运营** | 不出现「教你怎么做抖音／视频号」「起号技巧」；只讲不指向具体平台的通用方法（小店／课程口径 G1） |
| 8 | **收入只讲结构** | 「我有几种收入来源」，不讲「我一个月赚多少」 |
| 9 | **AI 内容标注** | 真人口播不涉；若用 AI 生成画面／数字人 → 必须标「AI生成」（2026-08-10 新规，不标直接限流） |

**抖音加检（同稿发抖音时必做）**：抖音对「教人做自媒体／涨粉／副业」识别更严。同一条稿上抖音 → 删掉「涨粉、起号、流量、爆款、变现、割韭菜」等词，改成认知与经历表述；标题带这些词的换标题；医疗／功效词同样清零。

**一句话记忆**：**讲我怎么做，不讲你能赚多少；讲我看见什么，不讲我判断你该怎样。**

#### 闸 C · 内容九关（质量闸 · 不过不交付）

> 依据 [[B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统|视频号脚本风格系统]]「八、写稿自检清单」压缩成本号九关。

| # | 关 | 判据 | 不过怎么办 |
|:-:|---|---|---|
| 1 | **稀缺关** | 这个观点别人讲过吗？有没有信息差／视角差／体验差／冲突差至少一个？ | 没差异 → 换切口 |
| 2 | **钩子关** | 前 3 秒「咯噔」一下；第一句之后有一个具体疑问，且前三句没答掉 | 重写开头 |
| 3 | **身份关** | ≥1 处具体场景（医院那几年／亏掉 30 万／700 粉到 2 万），落成场景或一句原话，且只作故事 | 补场景 |
| 4 | **故事关** | 结论由一个具体的人／一个场景／一句原话扛着；不是「判断→第一层→第二层」的清单开场 | 补故事 |
| 5 | **结构关** | 三个点递进不并列；每 30 秒一个钩子；有一句狠话 | 调结构 |
| 6 | **转发关** | 转发原子 ≥2 个（数字／账本／命名／比喻／分装），且落在中段、挂着场景；转的人手里有货 | 回 ⑤ 补原子 |
| 7 | **涨粉关** | 有一个能被观众带走的「命名概念」＋ 下一集测试（看完想不想看下一条）＋ 零产品 | 命名 |
| 8 | **口语关** | 读出声像说话；没有「第一／第二／所以／因此」；有一粒沙子；敢给朋友看 | 念一遍再改 |
| 9 | **人性关** | 至少一句「你不是 X，你是 Y」；至少一句能被复述的狠话；结尾落在「我这个人」 | 回 ② / ⑥ 改 |

**闸 C 收口 · 去 AI 味双引擎（强制 · 九关全过之后做）**

> 九关只证明"内容立住了"，不等于"读起来像人写的"。机器味没洗掉，前九关白过。

顺序固定，不能反：

1. **sepia review** — 只诊断、不改稿；中文在 style pass 那步加载 `references/languages/zh.md`
2. **sepia refactor** — 按诊断最小改动，先修结构（叙事架构／段落流／信息顺序），删改优先于新增
3. **humanizer-zh 词句扫描** — 24 条中文 AI 痕迹，清掉 sepia 改完残留的词句套路
4. **ai-detector 复核** — 分数只当风险估计，不当证据

**判据**：先结构、后词句。只跑一个就交付 = 闸 C 没过。

#### 闸 D · 交付格式（缺一不交）

- **口播正文**：纯文字，可直接照读，不留结构标记（无 `#`／`-`／`**`）
- **发布三件套**：标题 ／ 封面文案 ／ 简介
- **话题标签**：#张大侠 打头，总数 ≤4
- **权威锚点**：凡出现数据／研究／报告／趋势数字 → 文末给「结论 + 机构·篇名·年份 + 可点链接」；找不到出处 → 改保守表述或删掉（依据 [[F技能库skill/运行规则/01-合规网关|合规网关 0d]]）
- **入库**：`B自媒体大脑/04-超级个体自媒体创作/交付脚本库/`
- **附**：「🎯 本期测试变量」

## 二、三个对标：蓝宝宝给"入口"，姜胡说给"结构"，大麦哥给"信任"

### 2.1 蓝宝宝（认知觉醒）—— 一整套「人性表达系统」

> 粉丝 59 万＋、获赞 723 万＋。**他不教你怎么拍，他教你怎么让人停下。**
> 他不是技巧派，是人性派——技巧会过时，人性不会。所以他的东西能迁移。

#### 六条信条（他的原话）

| # | 信条 | 落到写稿上 |
|:-:|---|---|
| 1 | **道理只能让人点头，人性才能让人停留** | 开头讲他的处境，不讲普遍道理 |
| 2 | **先用人性把人留下来，再用干货让人信你** | 前 15 秒只留人，方法放后面 |
| 3 | **口播不是念稿子，口播是情绪表达** | 写成能"演"出来的话，不是能"读"出来的字 |
| 4 | **点赞是给作品的，关注是给人的** | 结尾落在"我这个人"，不落在"这条内容" |
| 5 | **技巧是刀，不是手** | 结构是刀，你的经历和判断才是手——每条必须挂事 |
| 6 | **短视频不是让所有人喜欢你，是让一部分人迅速认出你** | 每条只对一类人说话，敢让另一类划走 |

另一句他常说的：**"别自证，也别下场。真正的高手，只盯目标，不陷情绪。"**——不跟评论区吵架，只盯目标。

#### 三把刀（人性三切口）

| 刀 | 观众心里的原话 | 开头怎么用 | 句式 |
|---|---|---|---|
| **欲望** | "凭什么他有我没有" | 对比、结果前置 | "你不是不想要，你是不敢要" |
| **恐惧** | "我怕认真了还是没结果" | 损失预警、代价 | "最怕的不是没结果，是认真了也没结果" |
| **不甘** | "嘴上说算了，心里没服过" | 身份代入、戳穿 | "你说算了的时候，心里其实没服" |

> **三把刀同时只能用一把**。一把刀捅到底，比三把刀各划一下疼。

#### 知识点 → 人性句（他的核心改造法）

| 废句（知识点） | 活句（人性） | 改法 |
|---|---|---|
| 今天分享三个提升表达力的方法 | 表达差的人，不是不会说话，是太怕别人不舒服 | 把"方法"改成"病因" |
| 如何变得更自信 | 你不是不自信，你是太习惯把自己放在别人后面 | 你不是 X，你是 Y |
| 三个职场沟通技巧 | 真正会沟通的人，不是会说漂亮话，是敢把边界说清楚 | 不是 A，是 B |
| 做自媒体要坚持 | 做不起来，不是不坚持，是每天都在做没人看的东西 | 换靶子 |
| AI 会取代很多人 | AI 不会淘汰你，会淘汰"只会执行的人" | 把恐慌收窄成一句可指认的话 |

**动作**：写完初稿，把每一句"应该怎样"圈出来，改写成"你不是 X，你是 Y"。**全篇至少留一句。**

#### 四拍节奏（他的口播落点）

> **一句话戳穿 → 一巴掌扇醒 → 三条活路 → 一句狠话刻进 DNA**

- **戳穿**：说出他不敢承认的那句（人性层）
- **扇醒**：给一个他没想到的角度（这里才放你的专业和经历）
- **活路**：三条，具体到动作
- **狠话**：一句能被截图、被复述的话，收尾

#### 三率口诀（发布后诊断）

| 率低 | 问题在 | 改哪里 |
|---|---|---|
| **点击率** | 封面、标题、主页视觉不统一 | 统一封面色系和字体，标题给结论 |
| **完播率** | 开头没钩住 | 第一秒抛冲突／反差，不铺垫、不解释 |
| **吸粉率** | 主页没讲清"凭什么长期看你" | 主页三问：你是谁 / 你能帮我什么 / 为什么长期看你 |

一句话记忆：**戳得多深、留得多稳、接得有多准。**

#### 《认知觉醒》三条认知规律（当写作纪律用）

1. **焦虑＝想同时做很多事，又想立即看到效果** → 一条只解决一个焦虑。
2. **懂得百点，不如改变一点** → 一条只改一个认知。
3. **匹配：学习要在"跳一跳够得着"的区域** → 讲他当前能接住的那一层，不讲超越三步的东西。

#### 能迁移 / 不能照搬

- **能迁移**：人性入口、刀式开头、句式改造、四拍节奏、三率诊断、认知纪律。
- **不能照搬**：他的内容是"怎么做自媒体"本身；你的内容是"大健康超级个体怎么做成"。**学他的入口，不学他的题目。**

### 2.2 姜胡说（价值心法）—— 内容即资产

人设关键词：自学、坚持、真诚、利他、养成系、"弱点是卖点"。

固定骨架：

> **结论先行 → 为什么（逻辑/理论）→ 案例（自己的 / 真实的）→ 怎么做（一二三四五）→ 总结 + 行动号召**

选题四类：**卡点 / 评论区抱怨 / 反复被问的问题 / 反常识断言。**
（不追热点，是"攒"出来的——来自生活、读书、复盘、被问。）

内容即资产三问：

1. 用户是谁？
2. 我提供什么价值？
3. 我怎么交付好？

同一话题反复讲不是重复，是**每次理解更深、交付更好**。

表达特征：口语化（"就是""你会发现""对吧"）、短句、不装、结论前置、每 2–3 分钟一个认知高潮。

**能迁移的**：结论先行、五段骨架、选题四类、作品意识、口语化。
**不能照搬的**：他的资产是"自学方法论"；你的资产是"医生 + 大健康 + AI 的实操账本"。

### 2.3 合体：你的口播 DNA

> **蓝宝宝的入口 × 姜胡说的骨架 × 大麦哥的姿态 × 张医生的独家内容**

四者分工：

- 蓝宝宝负责**前 3 秒**：让人停下来
- 姜胡说负责**中间 60 秒**：让人服
- 大麦哥负责**整条的姿态**：让人不防着你
- 你负责**全部**：让人信、让人转

> **为什么补第四极**：前两极解决"怎么讲清楚"，解决不了"观众凭什么信你"。大麦哥用 5 年 200 条证明，**在一个人人抢前 3 秒的环境里，"慢 + 交底"本身就是筛选器**——愿意听完的人，就是高共鸣人群。

### 2.4 大麦哥（Michael大麦哥）—— "交底"这一极

**他是谁**：1985 年生，40 岁，香港出生、英国打工、苹果/阿里/美团，30 岁甲状腺癌，2022 年离婚，2023 年 38 岁被裁员，同年全职做自媒体。2022 年起发口播，200 余条长期两三位数点赞，**2026-10 一条 36 分钟《关于爱情，我终于想明白了的几件事》涨粉 448 万**，定制视频报价 12 万/条。

**他的表达内核**：

1. **位置先降**——先认自己的怂，再谈道理。"我在感情里特别容易逃避。"
2. **不给答案**——只给"我是怎么想的"，把观众从"同意/不同意"的擂台上放下来。
3. **允许答不上来**——网友问"怎么面对恋人离世"，他回"这个我也不知道，节哀"。**在能装的时候选择不装。**
4. **数量锚点**——6 件事 / 10 个方法 / 5 个允许。让大脑知道有边界、能跟完，长视频才立得住。
5. **不指责第三方**——不骂前任、不骂大厂、不骂时代。评论区不吵架，只有"我也是"。

**能迁移的**：自曝开场、N 件事结构、失败案例、留白结尾、不装姿态。
**不能照搬的**：他的"不装"是 5 年 200 条 + 真实履历攒出来的存量信任；**没有存量直接模仿，会显得空。** 另外他是成长号，可以永远不给答案；你是专业号，**观念层可以留白，事实层必须给答案**。

## 五、口播表达方法论（道）

### 5.1 六段骨架（90 秒标准版）

| 段 | 时长 | 任务 | 句式提示 |
|---|---|:-:|---|
| ① 人性钩子 | 0–3 秒 | 让人停 | 反常识 / 身份代入 / 损失预警 |
| ② 戳破伪装 | 3–15 秒 | 让人愣 | "你不是 X，你是 Y" |
| ③ 医生式拆解 | 15–45 秒 | 让人服 | 首先 / 第二 / 为什么会这样 |
| ④ 真实案例 | 45–70 秒 | 让人信 | 我自己 / 学员 / 临床，必须挂事 |
| ⑤ 三条活路 | 70–90 秒 | 让人做 | 具体到动作，不喊口号 |
| ⑥ 金句 + 号召 | 90–100 秒 | 让人记 | 压缩总结 → 金句 → 关注理由 |

### 5.2 开头七型（从两个对标提炼）

1. **反常识断言**："做自媒体最没用的事，就是天天追热点。"
2. **身份代入**："如果你也是那种'有专业、但不会表达'的人，这条别划走。"
3. **损失预警**："你现在做的这件事，正在把你自己做成一个可替代的人。"
4. **结果前置**："一个半月，我从 700 粉做到 2 万，只多了一个 AI 员工。"
5. **错误示范**："大部分人做知识库，第一步就做错了。"
6. **被问最多**："最近被问得最多的一句话是：医生做自媒体，会不会掉价？"
7. **场景切片**："凌晨一点，我在改第 7 版脚本，突然想明白一件事。"
8. **自曝型**（B 骨架专用）："我在医院那几年，最怕的不是抢救失败，是家属问我一句——医生，我们是不是早点来就好了。我当时答不上来。"

> **禁用**：悬念型、"今天给大家分享"、自我介绍开场、铺垫型。
>
> **自曝型与其余七型的区别**：前七型是"我抓住了你"，第八型是"我先把自己交出去"。它不追求前 3 秒的钩子强度，追求"这个人是真的，我听完再走"。**只用于 B 骨架，别硬塞进 90 秒。**

### 5.3 口语化三件事（写完必改）

1. **把书面语改成说出来的话**：不是"进行优化"，是"改一改"。
2. **短句**：一句话一个意思，超过 25 字就拆。
3. **数字和画面**：不说"很多人"，说"我群里 37 个人，34 个卡在这一步"。

### 5.4 结尾三件套（姜胡说式）

> **压缩总结（一句话回到开头）→ 金句（能被截图）→ 行动号召（只给一个动作）**

**本号固定追更钩**：**「相信未来，一起无限进步」**

- 理由：这句就是超级个体俱乐部的名字来源，也是本号的身份主张——观众记住的不是"我关注了一个人"，是"我属于一群相信未来的人"。
- 用法：每条结尾固定出现，一字不改。前面的真心话可以变，这一句不变，久了就是账号的声音签名。
- 与营养号区分：营养号用「关注我，分享更多有价值的内容」，本号用这一句，两个号不串味。

### 5.5 交底式表达（大麦哥 · 第三极 · 2026-11-10 增补）

> 前两节解决"怎么让人停下来、怎么让人服"。这一节解决第三个问题：**怎么让人愿意听你讲 8 分钟，并且不防着你。**
> 来源：Michael大麦哥（40 岁，做自媒体 5 年 200 条无人问津，2026-10 一条 36 分钟口播涨粉 448 万）。完整拆解见 [[A知识沉淀大脑/01-旧知识沉淀/04-短视频知识/自媒体研究/11-Michael大麦哥·成长选题全整理|大麦哥·成长选题全整理]] 第九节。

**两种表达的底层差别**

| 维度 | 说服式（蓝宝宝 × 姜胡说 × 医生） | 交底式（大麦哥） |
|---|---|---|
| 你站在哪 | 想明白了，来告诉你 | 也没完全想明白，来跟你对一对 |
| 观众的反应 | 被点醒 → 被推一把 | 被允许 → 松一口气 |
| 开场 | 3 秒钩子，抓 | 自曝一个具体行为，交 |
| 中段 | 三层因果 + 案例 + 三条活路 | N 件事，每件一个场景，不给答案 |
| 结尾 | 金句 + 号召 + 狠话 | 金句 + 留白 + 开放提问 |
| 风险 | 距离感、像在上课 | 没干货、被当成"正确的废话" |
| 适合 | 认知型 / 方法型 | 身份型 / 心力型 / 转折故事 |

**B 骨架 · 交底版（3–8 分钟，七段）**

| 段 | 时长占比 | 任务 | 句式 |
|---|:-:|---|---|
| ① 自曝 | 5% | 交出一个具体行为，不解释 | "我在医院那几年，最怕的不是……是……" |
| ② 替他审判 | 10% | 说出观众心里那句自我定罪 | "你是不是也觉得，是自己没做好" |
| ③ 声明边界 | 5% | 先卸掉"我来教你" | "我今天不讲方法，只讲这几年我想明白的 5 件事" |
| ④ N 件事 | 60% | 每件走四步：场景 → 旧认知 → 新认知 → 一句人话 | "我以前以为……后来发现……所以现在我会……" |
| ⑤ 主动示弱 | 10% | 承认有没做到的 | "第 3 条我到现在也没完全做到" |
| ⑥ 金句 | 5% | 对仗 + 往前看，可截图 | "别拿仅剩的力气，去攻击那个已经很难的自己" |
| ⑦ 开放提问 | 5% | 把话筒递回去 | "你有没有过那种，明明没错却一直在道歉的时候" |

**三条硬规则**

1. **删掉所有"你应该"。** 换成"我后来发现""我现在会"。命令句一出现，交底就变说教。
2. **全篇至少留一处"我也不知道"。** 这是可信度的锚点——**在能装的时候选择不装，比讲对十句更值钱。**
3. **不指责第三方。** 不骂同行、不骂平台、不骂某一类人。骂人涨粉快，但会把账号永久锁进情绪赛道，且评论区必吵架。

**什么内容必须用 B 骨架**

- 讲自己的转折（26 岁亏 30 万 / 从医院出来 / 700 粉到 2 万）
- 讲心力、内耗、坚持不下去
- 讲"我也曾经不信这件事"
- 任何你想让人"认识我这个人"而不是"学会一个方法"的选题

**什么内容不能用 B 骨架**

- 指标、疾病、方案类（**必须给确定答案，不能留白**——这是专业号和成长号的分界线）
- 需要立刻给动作的教学型
- 90 秒以内的短口播

> **一句话记法**：**A 骨架是"我教你"，B 骨架是"我陪你"。同一个账号，两条腿走路——只有 A 会累，只有 B 会空。**

## 八、起号路径（0 → 10 万）

### 8.1 三个阶段

| 阶段 | 目标 | 动作 | 判断标准 |
|---|---|---|---|
| **0–30 天** | 校准 | 20 条测试，六母题各 3 条 | 找到 1–2 条完播率明显高的 |
| **30–90 天** | 复制 | 把跑出来的母题复制 10 条 | 出现第一条 10 万+ |
| **90–180 天** | 成型 | 人设定型 + 产品化 | 有人主动问"怎么跟你学" |

### 8.2 三率诊断（蓝宝宝口诀 · 每周复盘用）

- 点击率低 → 改封面、标题、主页视觉统一
- 完播率低 → 改前 3 秒，砍铺垫
- 吸粉率低 → 改主页：头像 / 背景 / 简介三问

### 8.3 复盘节奏

- **每周**：三率 + 转发率，挑 1 条最好的拆结构
- **每月**：母题盘点，砍掉不涨的母题
- **不做**：发布 1 周内不做"归零复盘"（传播型内容的滞后性）

## 九、合规与风险（口播号专属）

> 口播号讲"自媒体 / 创业 / AI"，风险点和营养号完全不同，重点在**承诺**和**身份**。

1. **不承诺结果**：不出现"月入""涨粉多少""包会""保证起号"。
2. **不卖焦虑**：讲 AI 讲的是"结构变了"，不是"你完了"。
3. **医生身份只作故事层**：可以说"我在医院那几年"，但不能用医生身份给自媒体方法做专业背书，更不能涉及疾病 / 疗效。
4. **不教具体平台运营技巧**（涉及课程 / 小店时）：只讲不指向具体平台的通用方法。
5. **不站外引流**：不留微信、不做私下交易。
6. **收入只讲结构，不讲数字**：讲"我有几种收入来源"，不讲"我一个月赚多少"。

## 十三、为什么是现在（底层认知 · 2026-11-09 增补）

> 这一节回答一个绕不开的问题：**都 2026 年了，现在做自媒体晚不晚？**
> 答案不是"不晚"，是**这个问题本身问错了方向**。

### 13.1 三个判断

**判断一：自媒体不是风口，是底层游戏规则改了。**

过去话语权握在机构和平台手里；现在算法和移动互联网，把分发权交回给每一个普通人。这不是"一阵风"，是内容生产和分发方式的彻底重构。风会停，规则不会退回去。

数据支撑（可核验）：截至 2024 年 12 月，我国网民规模 11.08 亿，短视频用户 10.40 亿、使用率 93.8%；网络视听用户 10.91 亿，人均单日使用时长 156 分钟，全国每日上线短视频突破 1.3 亿条。

**判断二：机会一直在，但大多数人熬不到结果出现。**

门从来没关。关掉的是人的心态——一急，动作就变形：发三五条没爆就焦虑，三个月没收入就想撤。

**判断三：平台永远给新人机会，但它更喜欢持续稳定更新的人。**

我自己三个单账号从零做到二十万粉；张重复和卷毛比我晚一个多月，涨得比我快。差别不在天赋，在稳定——我中间停更过两周，他们没停。**平台奖励的不是爆发，是稳定。**

### 13.2 大多数人做不好，就三个原因

| 错法 | 症状 | 真相 |
|---|---|---|
| **心态错** | 一上来就想快速变现 | 自媒体是复利游戏，前期像种树，不能天天挖开土看根 |
| **方向错** | 什么火发什么，最后谁也没记住你 | 没有定位，算法贴不上标签，推荐就不精准 |
| **方法错** | 把创作等同于"拍视频、写笔记" | 表层是形式，内核是价值的持续交付 |

**定位三问**（方向错的解药）：
1. 你是谁——你的专业或热爱是什么？
2. 你在哪里——目标用户和平台选对了吗？
3. 你能提供什么价值——解决问题、启发思考，还是带来共鸣？

### 13.3 自媒体是人生杠杆，不是快钱工具

- **支点 · 独特定位**：你不需要完美，但需要真实且精准。
- **资产 · 内容复利**：写下的、录下的不会随时间贬值，反而持续带来新读者、新机会。
- **杠杆 · 撬动人生**：它带来的不只是流量收入，还有人脉、资源、跨界机会。

> 一句提醒自己的话：我一开始做自媒体，根本没想过靠它吃饭。**越不功利，路反而越顺。**

## 十四、为什么要做口播 + 什么样的口播有价值

### 14.1 为什么是口播（立项依据）

**第一，四两拨千斤。**
别人两天做一条九十九分的精品；同样的时间，口播能录十条六七十分的。爆款的概率本来就不完全可控——**做一条精品是运气，做十条合格作品才是策略。**

**第二，三个长在人身上的价值（不依赖流量）。**
1. **表达力飞跃**：镜头前没法"嗯嗯啊啊"，只能逼自己讲清楚。
2. **学习力上升**：为了讲，必须听懂、吃透、提炼框架。
3. **主体性觉醒**：有人因为"我这样"而喜欢你，你才开始真的相信自己。

**第三，三个很现实的好处。**
个人品牌背书 / 缓解经济与职场焦虑 / 倒逼自己成长。

### 14.2 有价值口播的五条标准（质量判据）

| # | 标准 | 反例 |
|:-:|---|---|
| 1 | **不是会说话，是有东西** | 段子、八卦、复读新闻 |
| 2 | **听完要有收获** | 讲完很热闹，什么也没留下 |
| 3 | **要有人格** | 记不住你是谁、值不值得信 |
| 4 | **要能看到趋势** | 搬运别人的观点，当复读机 |
| 5 | **要敢讲价值观** | 什么都不敢站队，谁都想讨好 |

> **一句话**：有价值的口播，不是"会说话"，是"有东西"——能让人得到收获、记住人格、看到趋势。

## 十五、工业化生产：选题 → 脚本 → 交付 → 运营

> 爆款不靠灵感，靠流程。**用理性的流程，包装感性的内容。**
> 本节是账号级的生产线；单条写稿仍以 [[AI观点口播账号·爆款公式与写作风格]] 为准。

### 15.1 第一步 · 选题（起号的基石）

**选题公式**：**爆款选题 = 受众面广 + 借势 + 价值 + 情绪**

- **受众面**：大众真正关心的命题就那几类——金钱、情感、认知、健康。
- **借势**：结合热点或平台活动，用实时流量池做冷启动。
- **价值**：给"对我有用"的干货，或"替我说话"的情绪。
- **情绪**：让人有转发和评论的冲动。

**对标拆三遍**（找同领域最近一周的爆款）：
1. 第一遍：记爆点（哪一句让人停）。
2. 第二遍：打算法标签（平台凭什么推它）。
3. 第三遍：翻高赞评论，找真正的火爆诱因。

**概率论**：爆款可复制 = 70% 成功经验复制 + 30% 随机性。改到 50%–60% 相似度，就具备再爆的潜力。

### 15.2 第二步 · 脚本（留存的关键）

- **黄金三秒**：第 2–5 秒必须出现冲突点或替代性结论。
- **三种开头模块**：观点先行 / 主角标签化 / 疑问式（"你知道为什么……吗"）。
- **预设互动槽点**：中段埋 2–5 个可讨论、可吐槽、可共鸣的点。
- **干货模板**：**否定 + 确定 + 运算 + 举例 + 建议**。
- **故事模板**：固定具体物件 → 导入冲突 → 转折 → 启发。
- **三种结尾**：引导式（问经历）/ 共鸣式（金句）/ 悬疑式（留钩子）。
- **去 AI 味（成稿必做）**：先 `sepia` review→refactor 修结构（中文＋zh.md），再 `humanizer-zh` 扫词句，最后 `ai-detector` 复核。顺序不能反。

### 15.3 第三步 · 交付（专业度的证明）

- **镜头感**：把镜头当朋友，目光看镜头上方的圆点，**不看屏幕里的自己**。
- **五点布光**：主光 + 辅光 + 轮廓光 + 顶光 + 背景光（让人从背景里"跳"出来）。
- **参数**：快门 = 帧率的两倍倒数（25fps → 1/50s）；低 ISO；**锁死白平衡**，别让肤色忽冷忽热。
- **收音**：外置麦优先，声音比画面更影响完播。

### 15.4 第四步 · 运营（破圈的引擎）

- **发布时机**：饭前、睡前高峰；固定时间，养粉丝习惯。
- **地域加成**：方言或地域内容，务必加定位。
- **神评论运营**：发布后用预设评论引导话题。
- **翻牌留存**：认真回复评论和私信。
- **老视频激活**：抖音有长尾，表现好的老作品持续点赞、评论保温。
- **剪辑节奏**：**7–20 秒**是纯流量切片的节奏；本账号主形态是 60–90 秒口播，7–20 秒只用于二次剪辑的引流切片，别把主片剪碎。

## 十六、起号四步法 + 每日 SOP

### 16.1 起号四步法

| 步骤 | 核心动作 | 关键指标 |
|:-:|---|---|
| 1 选题定位 | 借势热点、对标爆款、挖痛点 | 点击率 CTR |
| 2 文案结构 | 黄金三秒、评论埋点、互动结尾 | 评论率、转发率 |
| 3 交付 | 镜头感、五点布光、参数锁定 | 关注率、信任度 |
| 4 反馈 | 神评论引导、定时发布、数据复盘 | 完播率、粉丝转化 |

### 16.2 每日 SOP（30 分钟版）

1. 早上 10 分钟：翻对标账号最近 7 天爆款，记 1 个可拆的钩子。
2. 中午 10 分钟：写一条 60–90 秒口播稿，套六段骨架。
3. 晚上 10 分钟：发布 + 回评论 + 给 1 条老视频点赞评论保温。

> **和第八节的关系**：第八节管"三个月怎么走"，本节管"每天怎么干"。一个管方向，一个管动作。

# 🤖 AI 观点口播账号 · 爆款公式与写作风格

> **定位**：本规则服务 **AI 观点口播账号**——真人出镜、连续口播、不靠录屏演示，用「一个真实使用现场 + 一句反常识判断」讲清楚 AI 跟普通人到底有什么关系。
> **风格母本**：张机（@张机）的「平和克制 + 弱化自我 + 反成功学 + 真实案例与数字」。拆解见 [[A知识沉淀大脑/01-旧知识沉淀/04-短视频知识/自媒体研究/08-张机·商业访谈体与AI转型|08-张机·商业访谈体与AI转型]]。
> **与另两条线的分工**：
> - 安利主线口播 = 让人认同「张医生这个人」；
> - AI 录屏演示线 = 让人想「抄这套操作」；
> - **本线 = 让人相信「这个人对 AI 的判断」**。不教工具，讲判断；不秀操作，讲代价。

## 🚦 写稿流程·八步（写稿先看这里）

> 参照 [[B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统|视频号脚本风格系统]]「写稿流程·八步」，叠加 [[张医生-朋友圈写作流程规则-v3.3-说人话版|朋友圈 v3.2「洞见五步」]]，按本线「认知类 + 张机式冷静」改造为八步。**写每条都照此走，不跳步。** 后面的章节都是这八步的解释与素材库。

```
① 定选题（认知切口 + 靶子）
   ├─ 六母题选一（见「四、选题」）
   ├─ 三问：观众在问吗？只有你能讲吗？靶子能一句话指认吗？
   ├─ 定切口：纠偏 / 颠覆 / 升维（只选一个）
   └─ 一句话写出：这条要改的那个认知是什么？
        ↓
② 炼认知（洞见五步：现象 → 归因 → 命名 → 判词 → 加码）
   ├─ 现象：大家都看见的那个现象（1 句，具体）｜⚠️v1.6 起：**只做一句自我暴露**（"我一开始也这样"），不许展开"大多数人怎么用"——见十八节
   ├─ 归因：机制层——他为什么必然这样？（2–3 个生活化具象场景）
   ├─ 命名：给这个说不清的痛起个名字（可复述）
   ├─ 判词：一句定性收尾（是判断，不是指令）
   └─ 加码：判词后再拔 1–2 层（具象 → 系统 → 时代），结尾赌注 > 开头
        ↓
③ 写前设计（动笔前先定六要素，不定完不写）
   ├─ ① 判断句：这条要立的那句话（≤15 字）
   ├─ ② 现场：时间 / 地点 / 屏幕 / 对话（能看见）
   ├─ ③ 数字：至少 1 个可验证数字
   ├─ ④ 社交货币：观众转出去，手里拿的是什么？
   ├─ ⑤ 靶子：在反驳谁 / 哪句话？
   ├─ ⑥ 落点：观众明天能做什么？
   ├─ ⑦ 命名概念（认知类必选）：给现象起个名字
   ├─ ⑧ 判词：一句定性收尾，不是给指令
   └─ ⑨ 视角（v1.6 强制）：**第一人称实操体**——写"我做了什么 / 我怎么想 / 我怎么改的"，不写"很多人怎么用"。观点必须是"我的看法是…"，不是"你应该…"
        ↓
④ 写开场（8 秒内）
   ├─ 四型选一：数字反差 / 争议场景 / 结论前置 / 现场
   ├─ **故事承载（2026-10-21 强制）**：结论可以先出，但必须由"一个具体的人／一个场景／一句原话"扛住；⛔ 禁止"判断 → 第一层 → 第二层"式清单开场
   ├─ **第一句只准装「结果」**：数字 / 反差 / 结论三选一。**禁止**用"我学AI一年""今天我想聊""最近有个感受""先说个背景"开场——这些是背景，不是钩子
   ├─ **背景与履历一律延后**：身份、资历、时间跨度，放到第 3 段以后再出（承载结论的具体人／场景／原话不算背景）
   ├─ 前 3 秒不许自我介绍、不许「今天给大家分享」
   └─ 轮换检查：连续 2 条同句式 → 换
        ↓
⑤ 写正文（三层因果）
   ├─ 第一层：大家以为的原因（错误归因）
   ├─ 第二层：真正的原因（机制 + 2–3 个生活化具象场景）
   ├─ 第三层：判词（定性）+ 加码（再拔 1–2 层）
   ├─ 每层一个生活级比喻（一句话能转述）
   ├─ 数据错开排：数据 A → 画面 → 数据 B → 反问
   └─ 每 150–200 字开一个新问题，旧问题先给答案
        ↓
⑥ 写结尾（三型选一）
   ├─ 不劝人 / 给判断 / 留问题
   ├─ 先用判词定性收住，再用「加码」封顶（结尾赌注 > 开头）
   ├─ 金句上限 1 句，且必须从前面事实里长出来
   └─ 不喊「赶紧行动」、不承诺结果、不硬转产品
        ↓
⑦ 过质检（强制，见「十、自检清单」+「九、合规红线」）
   ├─ 8 关自检（过 6 关可发，低于 6 关重写）
   ├─ 禁用清单扫一遍（见「八」）
   ├─ sepia 去 AI 味（review→refactor·中文+zh.md）→ humanizer-zh 词句扫描 → ai-detector 复核
   ├─ content-risk-detector + 风控总表
   ├─ 涉及健康/营养 → 医疗合规三条红线 + 免责
   └─ 查重：洞见卡 / 知识卡 / 已有脚本
        ↓
⑧ 交付 + 入库
   ├─ 纯口播文案（可直接照读，正文不留【现场】【反转】【拆解】【实证】【落点】等拍点标记）
   ├─ 发布三件套（标题 / 封面文案 / 简介 + 话题标签）
   ├─ 话题标签：固定 #张大侠 打头，总数 ≤4 个，其余从内容提取
   ├─ 朋友圈转发文案（走朋友圈 v3.2 规则）
   ├─ 存入 B自媒体大脑/04-AI自媒体创作/交付脚本库/AI-script-X-NNN-xxx.md
   └─ 末尾附「🎯 本期测试变量」
```

### 认知类专项加检（在 8 关之外）

- [ ] 这条改的是**一个**认知，不是三个？
- [ ] 观众能用一句话复述「他改了我什么想法」？
- [ ] 有没有一个「明天就能试」的动作？
- [ ] 反常识的那句，有没有可查证据兜底？
- [ ] 有没有给现象起名字（观念类加分项）？
- [ ] 归因有没有 2–3 个生活化具象场景，让观众对号入座？
- [ ] 判词是「定性」，还是又在给指令？
- [ ] 结尾有没有「加码」（比开头高一层的封顶句）？
- [ ] 有没有无数据支撑的宏大叙事（「超越 99% 的人」）？有 → 换可查数字或删。

## 一、这条线是什么 / 不是什么

| 是 | 不是 |
|---|---|
| AI 趋势与判断 | AI 工具说明书 |
| 一个普通人的真实使用现场 | 「3 分钟学会」教程 |
| 讲代价、讲失败、讲边界 | 讲暴富、讲风口、讲躺赚 |
| 一条只回答一个问题 | 一条塞五个知识点 |
| 冷静叙述，留白 | 情绪拉满，喊麦 |

**一句话**：别人告诉你 AI 能干什么，你告诉观众 **AI 干不了什么，以及为什么**。

## 二、爆款公式：五拍 + 三问

### 2.1 五拍结构（场 → 反 → 拆 → 证 → 落）

| 拍 | 名称 | 时长 | 干什么 | 一句话标准 |
|:-:|---|---|---|---|
| 1 | **现场** Scene | 0–8s | 一个能看见的具体场景或数字 | 观众能在脑子里放出画面 |
| 2 | **反转** Turn | 8–15s | 一句反常识判断（结论前置） | 跟大多数人的直觉反着来 |
| 3 | **拆解** Logic | 15–90s | 三层机制：首先 / 第二 / 第三 | 讲「为什么」，不讲「是什么」 |
| 4 | **实证** Proof | 90–150s | 一个真实案例 + 一笔能算的账 | 至少 1 个可验证数字 |
| 5 | **落点** Landing | 150–180s | 普通人能做什么 / 不能做什么 + 一句冷静收束 | 不劝人，只给判断 |

> 黄金时长 **90–180 秒**；超过 3 分钟必须有一条完整故事线撑着，否则砍。

### 2.2 三问定生死（写完逐条过）

1. **转不转？——社交货币**
   观众转这条时，手里有没有一个能拿出去的东西？（一个数字 / 一笔账 / 一个说法）
   只给情绪 → 不转。
2. **吵不吵？——靶子可指认**
   你反驳的是一个具体的人、一个价位、一句人人说过的话，还是一种模糊的处境？
   后者 → 评论必死。
3. **涨不涨？——身份独占或命名概念**
   这条是「只有张医生能讲」，还是你给一个现象起了个名字？
   两个都没有 → 别指望涨粉。

### 2.3 一句话公式

> **一个能看见的 AI 现场 + 一句反常识判断 + 三层机制拆解 + 一笔能算的账 + 一句不劝人的落点。**

## 三、风格基调：张机式冷静 × 张医生式笃定

### 3.1 三不三要

**三不**
- 不喊：没有「家人们」「兄弟们」「宝子们」。
- 不承诺：不说「学会就能变现」「抓住风口」。
- 不堆金句：一条最多一句金句，且必须从前面的事实里长出来。

**三要**
- 要现场：每条至少一个真实场景（时间、地点、屏幕、文件、对话）。
- 要数字：每条至少一个可验证数字（分钟、次数、成本、比例）。
- 要给判断：结尾必须亮明「我认为」，不和稀泥。

### 3.2 你给的张机七条 → 本线落地成什么

| 张机风格 | AI 口播里的具体写法 |
|---|---|
| 平和克制、不煽动 | 情绪曲线压平，张力靠「信息差」不靠「嗓门」 |
| 弱化自我、让别人说 | 少讲「我多厉害」，多讲「我试了什么、结果打脸在哪」 |
| 问题驱动、不制造冲突 | 一条只回答一个具体问题，不逼观众站队 |
| 反成功学 | 先讲成本和失败，再讲结果；不卖「可复制的暴富」 |
| 纪实感 | 用真实屏幕、真实文件、真实时间戳当证据 |
| 真实案例 + 具体数字 | 数字必须能被观众复述，模糊词一律删 |
| 访谈体：开头引入 + 结尾收束 | 开头我讲「为什么做这期」，中间让「过程/案例」讲，结尾我讲「我的判断」 |

### 3.3 句子级八条

1. 句子短：平均 12–18 字，一段不超过 3 句。
2. 判断句开头，解释句跟上。「AI 替代不了营养师。至少现在替代不了。」
3. 数据句必须配一个「人」或一个「画面」，不许连续两段数据连排。
4. 少用「我们」，多用「我」和「你」。
5. 允许口语连接词：「其实」「说白了」「我跟你讲」，但每段最多一个。
6. 不用形容词堆情绪，用动词和数字。
7. 每 150–200 字开一个新问题，旧问题必须先给答案。
8. 结尾不喊口号，用一句「冷静的话」收住。

### 3.4 情绪曲线

```
低开（平静陈述）→ 中段一个小抬升（反常识/打脸）→ 冷静收尾（判断）
```

不做「高开高走」，不做「三段递进式激昂」。**平静本身就是差异化**——在满屏喊 AI 的赛道里，冷静反而稀缺。

## 四、选题：六个母题 + 靶子

| # | 母题 | 观众心里的原话 | 可指认靶子 |
|:-:|---|---|---|
| 1 | **替代焦虑** | 「我这行会不会被 AI 干掉？」 | 「AI 马上取代医生/营养师/设计师」这类断言 |
| 2 | **工具选择** | 「这么多 AI，我该用哪个？」 | 「必须用最贵的」「国产的不行」 |
| 3 | **普通人门槛** | 「我没学历没资源，能用吗？」 | 「AI 是精英的工具」 |
| 4 | **专业人用法** | 「同行都在用，我该怎么用？」 | 「医生不能用 AI 写东西」 |
| 5 | **一人团队** | 「一个人怎么干出一个团队的活？」 | 「必须招人才能做大」 |
| 6 | **信息差** | 「别人是不是知道我不知道的？」 | 「AI 已经没红利了」 |

**选题三问（不过就换题）**
1. 这个问题，观众真的在搜/在问吗？
2. 只有你能讲吗（亲历 / 专业身份 / 真实数据）？
3. 靶子能不能一句话指认？

## 五、开头库（四型 · 8 秒内）

**① 数字反差型**
> 「我用 AI 把一份营养方案从 40 分钟压到 6 分钟。但省下的 34 分钟，我全花在了另一件事上。」

**② 争议场景型**
> 「昨天有人当面跟我说，AI 就是智商税。我没反驳，我让他看我电脑。」

**③ 结论前置型**
> 「先说结论：普通人用 AI，最大的坑不是不会用，是方向从一开始就错了。」

**④ 现场型**
> 「凌晨一点，我在改第七版脚本。AI 把我前面六版全否了。」

**开头三条铁律**
- 前 3 秒不许自我介绍，不许说「今天给大家分享」。
- 第一句必须是判断或画面，不是背景。
- 故事承载（2026-10-21 强制）：结论可以先出，但故事必须真在——由一个具体的人／场景／原话扛住；"判断 → 第一层 → 第二层"式清单开场一律不用。

## 六、中段：三层拆解怎么写

不要「第一第二第三」地罗列知识，要按**因果链**拆：

```
第一层：大家以为的原因（错误归因）
第二层：真正的原因（机制）
第三层：所以结果会怎样（推论）
```

**写法要点**
- 每层给一个生活级比喻，一句话能转述。
- 每层结尾留一个钩子，别一次性说完。
- 数据错开排：数据 A → 一个画面 → 数据 B → 一句反问。
- 允许承认「我也不知道」，但要说清楚「我知道哪部分」。

---

## 七、结尾库（三型）

**① 不劝人型**
> 「你不用现在就信。你先去用一次，回来再判断。」

**② 给判断型**
> 「AI 不会淘汰你。它会淘汰你工作里，那部分『查一下就知道』的你。」

**③ 留问题型**
> 「你手里最重复的那件活是什么？评论区告诉我，下条我拿它做示范。」

**结尾三不**：不喊「赶紧行动」、不承诺结果、不硬转产品。

## 八、禁用清单（反模式）

写完扫一眼，出现任意一条就重写：

- ❌ 家人们 / 兄弟们 / 宝子们 / 姐妹们
- ❌ 震惊 / 炸裂 / 封神 / 必看 / 天花板
- ❌ 3 分钟学会 / 一条讲透 / 看完少走十年弯路
- ❌ 月入过万 / 轻松变现 / 副业躺赚 / 风口红利
- ❌ 连续两段以上「据某某机构」
- ❌ 连续三句以上金句堆砌
- ❌ 开头自我介绍 / 「今天给大家分享」
- ❌ 一条视频塞五个以上知识点
- ❌ 只讲成功，不讲代价
- ❌ 用「我们」代替「我」来躲责任

## 九、合规红线（本线专属）

- **不承诺收益**：不出现「学完能赚钱」「副业月入 X」。
- **不诱导副业**：可以讲效率，不可以讲「辞职做 AI」。
- **境外 AI 工具**：演示/推荐前过「星光违规解密（0c）」，不做翻墙教程、不导流。
- **医疗边界**：涉及营养/健康建议，必须加「不替代医生诊疗」；不展示 AI 直接给患者开方案。
- **不贬低具体同行/品牌**：靶子打在「观点」和「现象」上，不打在人身上。
- **数据必须点名出处**：机构、年份、样本，至少给两个。

## 十、自检清单（视频号通用关 + AI线专项关 · 交付前逐条打勾）

> **本清单已与《视频号脚本风格系统》「八、写稿自检清单」逐条对齐。** AI 线不是另一套标准；要上视频号，先过视频号的关，再过 AI 线的关。
> **执行顺序**：一票否决 → 创作原理 → 开头 → 中间 → 结尾 → 整体 → 权威背书/文献 → 医疗合规 → 真实感 → 涨粉复核 → 转发复核 → 个人味道 → AI线专项 → 工具复核。
> **不过不交付**：一票否决项不过 → 直接换题或重写；其余项不过 → 当场改，改完再交付。

### 0. 一票否决（先过这 5 条）

- [ ] **0号闸门**：落点是不是健康科普？是 → 换题；账号无职业资格认证，健康科普一票否决。
- [ ] **涨粉配比闸门**：前面是否已连拍 3 条流量型？是 → 本条必须改成「医生为什么」身份独占型（涨粉切口「学／开」），否则不交付。
- [ ] **零产品铁律**：全篇有没有产品名/品牌词/购买暗示？有 → 删。
- [ ] **收益/副业承诺**：有没有「学完能赚钱」「副业月入 X」「辞职做 AI」？有 → 删。
- [ ] **医疗合规**：疾病词/功效承诺/点对点方案/引导问诊/联系信息 → 0 命中；涉及健康场景按第 7 条全过。

### 1. 创作原理（本质关）

- [ ] 创造稀缺：这条观点观众能在别处听到吗？不能才过关。
- [ ] 有信息差、视角差、体验差、冲突差、表达差至少一个。
- [ ] 放大情绪：观众看完会不会「咯噔」一下？
- [ ] 情绪有「推高→释放」的过程，不是全程平淡。
- [ ] 反差人设：有一个「嗯？」的反差点。

### 2. 开头（3秒）

- [ ] 第一句能让观众心里「咯噔」一下。
- [ ] 用了九大人性钩子之一（视觉/高价值/赚钱/恐惧/愤怒/炫富/八卦/猎奇/热点）。
- [ ] 第一句是判断/数字/画面，不是「我学AI一年」「今天我想聊」「先说个背景」。
- [ ] **信息缺口·设缺口**：第一句之后，观众有一个具体疑问（「那到底…？」）；没有 → 是陈述不是钩子。
- [ ] **信息缺口·别填平**：这个疑问没在前 3 句被答掉；答掉了 → 重排顺序（结论可前置，原因/过程必须扣住）。
- [ ] **价值密度前置**：前 15 秒有一个新事实/新角度/新数字/新比喻；只有情绪壳 → 补价值点。
- [ ] **守正出奇**：反常识观点有可查出处顶着；没有 → 重写或降级。
- [ ] **故事承载（2026-10-21 强制）**：结论/判断有没有"一个具体的人／一个场景／一句原话"顶着？只有判断、没有人 → 补；是"判断 → 第一层 → 第二层"清单开场 → 重写。

### 3. 中间（结构）

- [ ] 有一个「嗯？」的认知翻转点。
- [ ] 三个点递进，不是并列。
- [ ] 用对话/场景代替讲道理。
- [ ] 有一句狠话/大实话。
- [ ] 每 30 秒有一个让人停不下来的钩子（新问题/新数据/新反转）。

### 4. 结尾（CTA·v1.33 四段式）

- [ ] 四拍齐全：①金句总结 → ②呼吁 → ③真心话 → ④追更钩。
- [ ] 结尾金句从前面事实里长出来，不是硬贴。
- [ ] 最后一句是固定追更钩「关注我，分享更多有价值的内容」。
- [ ] 互动钩子过医疗合规：纯认知互动，不引导问诊、不讨论病情。

### 5. 整体（语调）

- [ ] 读出声像平时说话。
- [ ] 教学感过渡词（第一/第二/所以/因此）已清零。
- [ ] 情绪有起伏，不是一条直线。
- [ ] 敢给朋友看。

### 6. 权威背书 + 文献锚点（强制）

- [ ] 核心观点至少 1 个权威来源（官方数据/期刊/国家政策/专家共识）。
- [ ] 出处写清楚：机构/期刊/年份/样本，不是「有研究显示」「专家说」。
- [ ] ≥2 条锚点，且「国外权威 + 国内权威」并存。
- [ ] 正文点名出处，不只放在文末锚点区。
- [ ] 每个数字可溯源；拿不准 → 标「待核验」或删。
- [ ] 数据保守表述，不夸大；转发者转出去不会被反驳。

### 7. 视频号医疗合规（强制）

- [ ] **账号级前提**：账号无职业资格认证 → 健康科普一票否决；主力走创业线（AI/个人经历/团队/行业认知）。
- [ ] **疾病词清零**：血糖/血压/血脂/脂肪肝/糖尿病/心梗/胆固醇/慢性病/炎症/心血管/指标 → 标题/正文/简介/标签/朋友圈 0 命中。
- [ ] **无健康成果故事**：「补了XX睡得着了/不喘了/指标变了/精神好了」→ 0 命中。
- [ ] **无点对点方案**：「我帮你/给你调理XX」「你这种情况应该…」→ 0 命中。
- [ ] **医生身份只当故事**：「我在医院干过」✅；「以我经验你应该…」❌。
- [ ] **无医疗隐喻**：「开处方/开方/修复/调回去」→ 0 命中。
- [ ] **数据当论据**：数据保守表述 + 权威出处（可点击链接）；营养/健康类结尾口播+简介双免责。
- [ ] **落点检查**：删掉全文「我」再读，剩的是「观念/方法/行业」还是「健康知识」？剩前者 ✅。
- [ ] **不引导问诊**：没有「评论区告诉我，我帮你分析」「把体检报告发我」「私信我帮你调理」。
- [ ] **不引导公开讨论病情**：没有让观众「评论区说说你的病/指标/症状」。
- [ ] **不引导平台外学医/领资料**：没有「加微信/公众号领健康资料、教你调理」。
- [ ] **无联系信息**：视频/标题/简介/评论/合集/定位 → 无微信/电话/公众号。
- [ ] **创业/AI类如涉及健康场景，也按本关自查。**

### 8. 真实感（追加关）

- [ ] 读出声像跟朋友聊天，不像讲课。
- [ ] 没有教学感过渡词（第一/第二/所以/因此）。
- [ ] 每段最后一句让人想知道「然后呢？」。
- [ ] 有一粒「沙子」：一句没必要说、但说了就真了的话。
- [ ] 有完整故事弧线：目标 → 困难 → 变化 → 结果。

### 9. 涨粉复核（强制）

- [ ] **⓪ 涨粉配比闸门**：同第 0 条，满 3 条流量型 → 第 4 条必须身份独占型。
- [ ] **① 零产品铁律**：涨粉型整条不出现产品名/品牌词/购买暗示。
- [ ] **② 每个传播原子有明确转发对象**：写稿时想好「转给谁」；对象越具体，转发率越高。
- [ ] **③ 删我测试**：删掉全文「我」，还剩什么？剩不下 = 身份是内容本身 = 过关；删了还成立 = 换选题或加独家视角。
- [ ] **④ 下一集测试**：观众看完会期待下一条吗？答不出 = 没锚定长期价值。
- [ ] **⑤ 成长弧线**：有一处「自我暴露 → 主动补位」。
- [ ] **⑥ 传播原子 ≥2 个**：至少两个能一句话转述的比喻/数据/金句。
- [ ] **⑦ 命名概念**：有一个能被观众带走的「词」；涨粉预测按分型写——情绪/共鸣型 0.3%–0.5%，命名概念型 0.6%–0.8%。

### 10. 转发复核（强制）

- [ ] **① 社交货币**：观众转这条，手里有没有可引用的数字/一笔账/一个分装包/一句话？空手 → 转不动。
- [ ] **② 靶子可指认**：靶子是一个人/一个东西/一个价位/一句人人说过的话；不是一种处境/身份/观念。
- [ ] **③ 文献错开排**：没有连续两段同构「某机构算过一笔账」；中间插故事/画面/反问。
- [ ] **④ 数据分型**：留人型看 3s 率+完播；传播型看转发率+裂变系数；别拿完播判传播型。
- [ ] **⑤ 转发去向**：关心型（进朋友圈）还是说服型（进私聊）？想上 10% 朋友圈占比，必须另配情感型对象。

### 11. 个人味道嵌入（强制）

- [ ] 身份故事 ≥1 个，匹配线别（营养线取学医组；创业线取转型组+农村组）。

## 十一、示范稿（完整 · 套五拍）

**题目：AI 替代不了营养师，但它会端走最值钱的那 40 分钟**

【现场】
上周三凌晨一点，我在给一个客户改方案。第七版。
改到第三个小时，我把同样的问题，原样喂给了 AI。

【反转】
它 6 分钟给了我一份。结构比我清楚，措辞比我客气。
那一刻我没高兴。我有点慌。

【拆解】
先说第一层。AI 比我快，不是因为它比我懂营养，是因为它不累。
我改到第三版的时候，判断力已经下降了；它改到第三十版，还是那个状态。
第二层。但客户最后签的，不是那份方案，是我。
方案谁都能生成，出了事谁负责，只有一个人。
第三层。所以真正值钱的，从来不是「知道」，是「敢负责」。
AI 能把「知道」做到 90 分，但「负责」这件事，它连门都没进。

【实证】
我算过一笔账。
一份方案 40 分钟，AI 6 分钟，省下 34 分钟。
这 34 分钟我没拿去接更多客户。我拿去做了三件事：见人、复盘、拍视频。
三个月下来，客户数量没变，续费翻了一倍。
不是我变厉害了，是我终于把时间花在了 AI 干不了的地方。

【落点】
所以你别问 AI 会不会抢你饭碗。
你先问自己一句：你的饭碗里，有多少是「查一下就知道」的东西？
那部分，已经被端走了。
剩下的，才是你的。

> 说明：本稿为写作示范，数据为个人经历叙述，不构成收益承诺；发布前仍需过合规网关，并走 sepia → humanizer-zh 双引擎去 AI 味。

## 十四、认知类内容专项（本线主内容类型）

> 本线默认讲**认知**，不是讲工具。判断标准只有一句：**观众看完，是「学会了一个操作」，还是「换了一个看问题的角度」？** 后者才是认知类。

### 14.1 三种认知切口

| 切口 | 结构 | 传播力 | 涨粉力 | 适用阶段 |
|---|---|:-:|:-:|---|
| **认知纠偏** | 你以为 A，其实 B | 中 | 中 | 起号期最稳 |
| **认知颠覆** | 大家都在做 A，但 A 是错的 | 强 | 弱 | 有把握时用 |
| **认知升维** | 你看到的是 A，背后其实是 B | 中 | 强 | 需要身份或命名概念 |

**一条只选一个切口。** 既纠偏又颠覆又升维 = 观众一个都记不住。

### 14.2 认知类三条铁律

1. **一条只改一个认知。** 写完问：观众能用一句话说出「他今天改了我哪个想法」吗？说不出 → 重写。
2. **反常识 ≠ 反事实。** 出奇必须挂可查证据（机构/年份/样本），否则是造谣不是洞见。
3. **认知必须能落地成动作。** 结尾给一个「明天就能试」的动作；给不出 → 这条是鸡汤。

### 14.3 靶子与命名概念

- **一级靶子**：一句人人说过的全民共识话（「AI 会取代所有人」「学 AI 得会编程」「AI 都是智商税」）→ 评论最容易吵起来。
- **二级靶子**：具体产品 / 价位 / 人物。
- **三级靶子**：一种处境 / 身份（最弱，别单独用）。
- **命名概念**：给现象起一个可复述的名字（例：「40 分钟陷阱」「工具幻觉」「AI 到账率」）。**观念类内容的涨粉开关**——不带身份也能涨粉。

### 14.4 认知类 vs 知识类（别写混）

| | 认知类（本线） | 知识类（录屏线） |
|---|---|---|
| 观众收获 | 换一个角度看问题 | 学会一个操作 |
| 核心指标 | 转发 / 评论 | 收藏 / 关注 |
| 证据形态 | 判断 + 案例 + 账 | 屏幕 + 步骤 + 结果 |
| 结尾 | 一句判断 | 下一步动作 |

### 14.5 深度认知五步（迁移自朋友圈「洞见五步」· v1.3）

> 朋友圈 v3.2 的「洞见五步」是短文里炼认知的成熟工具，口播直接搬过来，作为写稿流程第②步的骨架。

| 步 | 名称 | 做什么 | 合格标准 |
|:-:|---|---|---|
| 1 | 现象 | 大家都看见的那个现象 | 一句话说清，具体不抽象 |
| 2 | 归因 | 机制层：他为什么必然这样 | 先合理化对方，再指出这个合理化正在杀死他 |
| 3 | 命名 | 给说不清的痛起个名字 | 可复述、可迁移（如「黑洞期」） |
| 4 | 判词 | 一句定性收尾 | 是判断，不是指令 |
| 5 | 加码 | 判词后再拔 1–2 层 | 具象 → 系统 → 时代；结尾赌注 > 开头 |

**关键在第 2 步。** 不骂「你懒」，而是解释「你为什么必然这样」。共情越准，刀越深——这是认知暴击和普通鸡汤的唯一分水岭。

**归因必须给 2–3 个生活化具象场景**，让对方对号入座，不能停在抽象。

**AI 线示例**：
- 现象：很多人学了半年 AI，还是没变化。
- 归因：不是不会用，是「学了没有地方用」——工作里最花时间的那三件事（写周报、回消息、做表格），他一件都没交给 AI。
- 命名：「练习场缺失」。
- 判词：「你不是没学会 AI，你是没有一场非用不可的仗。」
- 加码：往上一层，不是工具问题，是你从来没被逼到必须提效的位置；再往上一层，AI 淘汰的不是不会用的人，是没有真问题的人。

### 14.6 六步生成链路（一条认知从哪来）

```
观察/触发（客户案例、伙伴困惑、行业怪象）
  → 情绪/困惑（这事不对劲）
  → 深度归因（平台逻辑 / 人性弱点 / 时代变化）
  → 模型提炼（一句话公式或方法）
  → 自我投射（我也这样走过 → 验证）
  → 行动号召（评论区互动 / 来找我 / 预告）
```

**用法**：日常把「客户一句吐槽、伙伴一个卡点、行业一个怪象」记进素材池；写稿卡住时，从「情绪/困惑」倒推，比从「知识点」正推更容易出深度。

### 14.7 三个立判断机制

- **反平均主义**：敢承认差距——「贫富差距存在，认知差距更存在。」
- **结构化**：第一、第二、第三，降低理解门槛。
- **逆向思考**（两式）：
  - 人版：把缺点翻成优势——「内向的人更适合做 IP，因为更会观察情绪。」
  - 环境版：把行业乱象翻成机会——「大多数人都很水，但正因为这样，才轮得到你。」

### 14.8 等式库（可直接复用的判断公式）

- 营养专业 × AI × 安利系统 = **AI 营养师**
- 1 个 IP + 1 个助理 + AI = **百万级轻运营**
- 一份功夫 × 四倍流量 = **一鱼多吃**
- 方向 × 系统 × 坚持 = **普通人的逆袭**
- 信任 =（专业度 × 可信度 × 亲密度）÷ **自我推销感**

**用法**：等式是「可带走的社交货币」，一条片子最多用一个；连甩三个 = 观众一个都记不住。

### 14.9 认知深度专项自检（叠在 8 关之后）

- [ ] 归因有没有 2–3 个生活化具象场景？
- [ ] 有没有命名？名字能不能被观众复述？
- [ ] 判词是「定性」还是「给指令」？
- [ ] 结尾有没有加码（比开头高一层）？
- [ ] 有没有无数据支撑的宏大叙事？有 → 换可查数字或删。
- [ ] 等式有没有超过一个？

### 14.10 迁移提醒：朋友圈 ≠ 口播

| | 朋友圈（短文） | AI 口播 |
|---|---|---|
| 长度 | 100–300 字 | 90–180 秒 |
| 证据 | 判词 + 命名通常够 | 必须再加「现场 + 数字 + 一笔账」 |
| 归因 | 2–3 个场景 | 2–3 个场景 + 一个可验证结果 |
| 互动 | 评论区扣 1 | 结尾留问题 / 给判断 |
| 风险 | 宏大叙事容易混过去 | 口播会被追问证据，标准更严 |

**一句话**：朋友圈靠「对号入座」，口播靠「现场 + 账」。五步炼的是脑子的深度，口播还得补上眼睛能看见的证据。

## 十七、口语化 · 把稿子从「写」改回「说」（2026-10-20 定 · 强制）

> 病根一句话：**稿子是"写"出来的，不是"说"出来的。** 逻辑对、结构齐、数据全，但一张嘴就干——因为它长得像文章，不像一个人在跟你讲话。

### 17.1 一稿三干，先认病

| 干在哪 | 症状 | 后果 |
|---|---|---|
| **结构干** | "先说第一层。第二层，真正的原因。第三层。" | 像讲课提纲，观众在听汇报 |
| **句子干** | 一句一行，句句等长，全是判断句 | 没有呼吸，听三句就累 |
| **观点干** | 术语直接抛："认知差""沉淀标准""复用" | 观众点头，但没真懂 |

### 17.2 五刀改稿法（写完必过）

**第一刀 · 拆序号**
- 删掉「第一层 / 第二层 / 第三层」「首先 / 其次 / 再次」「第一 / 第二 / 第三」这类结构词。
- 换成人的说话方式：**我一开始也这么想 → 后来我才想明白 → 你想想平时大家怎么用它的 → 说白了 → 我不是这么干的 → 所以真正的差距在哪儿**。
- 判断标准：把每段开头的第一句单独连起来读，像不像一个人在跟你聊，还是在念目录。

**第二刀 · 调句子**
- 禁止一句一行。允许一段 2–4 句，让话说完整。
- 长短必须错落：**长句铺开（交代背景、举例、算账）＋ 短句收（下判断、砸金句）**。
- 每 3–4 段留一个**独立成段的短句**当停顿（"说白了"那句话），这是说话的呼吸位。

**第三刀 · 观点落地**
核心观点一律走**三层翻译**，缺一层就是没讲懂：

| 层 | 做法 | 例子 |
|---|---|---|
| ① 术语 | 先把概念说出来 | 大多数人不会带教 AI |
| ② 比喻 | 立刻换成一个生活场景 | 新员工第一天来上班，你连他叫什么都不知道，直接推上台讲课 |
| ③ 你的生活 | 拉到观众自己身上 | 你下次打开，又得从头告诉他你是谁、你的观众是谁——你每天都在换一个新员工 |

> 铁律：**一个核心观点，只配一个比喻，比喻必须来自打工/上班/带人这类人人有过的经验。** 不用科技比喻、不用体育比喻、不堆比喻。

**第四刀 · 数据说人话**
- 给完数字，**下一步必接一句"翻译成人话就是……"**，不许让数字自己站着。
- 反例：AI 提效 40%，质量提升 18%。
- 正例：时间少了 40%，质量高了 18%。**翻译成人话就是，AI 不是给高手锦上添花的，是给普通人补短的。**

**第五刀 · 加人味，但限量**
- 可用：说实话 / 我跟你讲 / 你想想 / 你想啊 / 说白了 / 这事儿 / 其实 / 可问题是 / 有意思的是 / 可能有点刺耳。
- 用量：**整条不超过 5 处**，每段最多 1 处。多了就油，变成短视频腔。
- 可加一句自我暴露（"我一开始跟你们一样""我也觉得得学技能"），降低说教感。

### 17.3 书面语黑名单（出现即改）

因此 / 综上 / 由此可见 / 值得注意的是 / 与此同时 / 进行 / 予以 / 该 / 其 / 之 / 基于此 / 综上所述 / 众所周知 / 不难发现 / 笔者认为

→ 一律换成：**所以 / 说白了 / 你看 / 这事儿 / 我就发现 / 我后来想明白了**

### 17.4 交稿前通读测试（强制）

1. **出声念一遍**，卡壳的地方就是句子太干，改。
2. **数独立成段的行数**，超过全篇 40% → 说明还在"一句一行"，回去调。
3. **找核心观点**，每个核心观点后面有没有跟一个比喻？没有 → 补。
4. **找数字**，每个数字后面有没有"人话翻译"？没有 → 补。
5. **数语气词**，超过 5 处 → 删。

### 17.5 与其它规则的关系

- 本节只管**表达层**，不动骨架。五拍、三问、六母题、洞见五步照旧。
- 口语化 ≠ 松散：**结构可以隐，逻辑不能断。** 删掉的是"第一层"这三个字，不是那层递进关系。
- 口语化 ≠ 说废话：每一句删掉后如果信息量不减，就该删。

## 十八、叙事视角 · 去现象，写自己（2026-10-20 定 · 强制）

> 一句话：**别讲"大家怎么用"，讲"我怎么用"。** 观众不关心人类的普遍困境，只关心一个跟他像的人具体做对了什么。
> 写法名称：**第一人称实操体**。

### 18.1 三条禁用

1. **禁开现象段**。不许出现"很多人问我""大家以为""大多数人都"开头的整段分析。现象最多一句，且必须转成自我暴露：**"我一开始也这样"**。
2. **禁替别人总结心理**。"你打开，问一句，然后失望地关掉"——这是在替观众演。改成**"我打开，问一句，看了半天，关掉"**。
3. **禁说教句**。"你应该""你要记住""千万不要" → 一律改**"我是这么干的""我的看法是""我不太认同那句话"**。

### 18.2 五段实操骨架（替代现象→归因）

| 段 | 内容 | 例子（X-001 实稿） |
|---|---|---|
| ① 我的起点 | 时间 + 身份 + 我原来干什么 | 我学AI，到今天正好一年；我原来是麻醉医生 |
| ② 我的错法 | 我自己怎么用错的（不写别人） | 用了大概一个月，我给它的评价是：一个会说话的搜索框 |
| ③ 我的转折 | 一句话讲清我怎么想通的 | 我不是在跟一个工具对话，我是在跟一个人说话 |
| ④ 我的动作 | 具体到可复制的操作 | 我新建一个文档，第一行写我是谁，第二行写观众是谁，第三行写我讨厌什么 |
| ⑤ 我的判断 | 我的看法，不是通用真理 | 我的看法是，AI淘汰的是那些没有判断、只会执行的人 |

> ⚠️ **顺序铁律**：①「我的起点」是**内容顺序**，不是**开口顺序**。开口第一句永远先给结果（数字/达成），起点和经历放到第 3 段以后。**"我学AI一年"不能当第一句，它只能当第三句。**

### 18.3 观点必须挂事

**每一个观点后面，必须跟一件我亲手做过的事。** 没挂事的观点＝空话，删掉。

- 观点：门槛不在会不会用，在于你有没有东西可以教它
- 挂事：改到第29版，它开始反过来管我，列三个理由否掉我想拍的题

### 18.4 个人经历怎么用（选 1–2 处，不铺开）

- **只用能解释观点的经历**：麻醉医生近十年 → 解释"判断比技术值钱"；学AI一年 → 给出时间尺度，证明不是天赋。
- **不给完整履历**。不讲学历、不讲奖项、不报年龄，除非那句话本身就是观点。
- **经历要短**：一处 1–2 句，讲完立刻回到"所以我怎么做"。

### 18.5 与十七节的关系

- 十七节管**怎么说**（口语化），十八节管**谁在说**（视角）。两节叠加才是完稿标准。
- 改了视角，全文要重排段落，不是把"大家"替换成"我"就完事。

### 18.6 交稿前三问

1. 通篇主语是不是"我"？出现"大多数人/大家/很多人"当主语超过 1 次 → 改。
2. 每个观点后面有没有一件我做过的事？没有 → 补或删观点。
3. 有没有一句是在教观众做人？有 → 改成我自己的做法。

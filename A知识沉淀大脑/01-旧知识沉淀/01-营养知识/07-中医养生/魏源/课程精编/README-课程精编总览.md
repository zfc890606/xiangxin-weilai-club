# 魏源老师课程精编 · 总览

> 把魏源老师 16 个视频、约 13 小时的逐字稿，从「口语讲座」重构为「按主题疾病划分的专业课程文档」。
> 每个模块都按同一条逻辑链写：**中医理论 → 现代机制 → 人群识别 → 分型 → 清调补方案 → 营养素配伍 → 饮食作息 → 误区 → 合规红线**。

## 三、这套文档怎么用

### 3.0 十讲课程排期（可直接照着开课）

| 讲次 | 主题 | 学员带走的一个动作 | 建议时长 |
|---|---|---|---|
| 第 1 讲 | 总纲：魏源养生体系与汉本萃产品地图 | 画出自己的「五脏—症状—产品」一张图 | 60—90 分钟 |
| 第 2 讲 | 肝胆：护肝、清肝与排毒 | 给自己做一次「伤肝行为」盘点 | 90 分钟 |
| 第 3 讲 | 肠道：便秘、菌群与七天清肠 | 做一次 7 天清肠并记录排便 | 60—90 分钟 |
| 第 4 讲 | 脾胃与祛湿：胃黏膜、脾虚与湿气 | 连续 7 天按「三餐结构」吃 | 90 分钟 |
| 第 5 讲 | 肾与养神：精力、睡眠与抗衰 | 连续 7 天固定入睡时间 | 90 分钟 |
| 第 6 讲 | 气血与女性：气血虚、月经与面色 | 做一次「吸收力」自评 | 90 分钟 |
| 第 7 讲 | 脑与视力：记忆、近视与干眼 | 执行 20-20-20 + 每天户外 1 小时 | 60—90 分钟 |
| 第 8 讲 | 结节：甲状腺、肺与乳腺 | 整理自己的检查报告与随访时间 | 90 分钟 |
| 第 9 讲 | 早餐与全域抗衰：代谢、血管与免疫 | 换掉一顿早餐的三个东西 | 90 分钟 |
| 第 10 讲 | 方法论：清调补、营养构建 123 与答疑 | 用三段式讲一个自己的案例 | 90 分钟 |

> 建议顺序：先讲第 1 讲建立地图，再按「肝胆 → 肠道 → 脾胃 → 肾 → 气血 → 脑眼 → 结节 → 早餐」讲，最后用第 10 讲收口。也可以按听众需求单讲某一模块。

### 3.1 讲微课
一次课讲一个模块，按「现象 → 机制 → 分型 → 方案 → 误区」走。每模块的「课程金句」可直接做开场或收尾。

### 3.2 一对一咨询
先看「高危人群与自检清单」定位问题，再用「分型」判断方向，最后从「分阶段方案 + 营养素配伍」里取组合。不要跳过分型和就医红线。

### 3.3 带教伙伴
让伙伴先背每个模块的「一句话本质 + 三类人 + 三个阶段」，再学产品配伍。先会讲逻辑，再讲产品。

## 四、证据等级与合规边界

全文统一使用三种标注：

- **【课程观点】** 魏源老师原话或课程体系说法
- **【现代医学】** 主流生理、病理、营养学可解释的部分
- **【整理】** 根据课程做的归纳、推论与方案设计

必须守住：

1. 汉本萃全线产品是**普通食品/植物饮料，不是药品**，不治病、不替代药物、不做疗效承诺。
2. 涉及结节、肝病、胃病、肾病、甲状腺疾病等，**先到医院明确诊断**，本方案只做生活方式与营养支持。
3. 课程中缺乏循证依据的说法（如「体温 36.6℃ 与癌症相关」「电磁波导致结节」「肝胆排石」等），只保留在【课程观点】里，**不建议对外直接引用**。
4. 对外讲课统一说「营养素」，不叫「保健品」。

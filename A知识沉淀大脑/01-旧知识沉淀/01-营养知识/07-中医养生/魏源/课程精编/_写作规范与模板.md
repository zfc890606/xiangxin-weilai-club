# 写作规范与模板（所有模块统一遵守）

## 一、这份文档是什么

把魏源老师的口语逐字稿，重构为**可讲课、可带教、可一对一使用的专业知识文档**。

要求：不是把逐字稿缩写一遍，而是按「理论 → 机制 → 识别 → 方案 → 产品 → 误区 → 合规」的专业逻辑重新组织。逐字稿是素材，不是结构。

## 三、内容质量要求

1. **详细**：每个模块不少于 6,000 字，目标 8,000—12,000 字。宁可把一个机制讲透，不要罗列空话。
2. **有逻辑链**：每个结论都要能回答「为什么」——为什么这个脏腑会出问题、为什么这个营养素对得上、为什么这个阶段要先做这一步。
3. **分层**：把人群分成 2—4 型（如肝郁型/湿热型/血虚型），每型给不同的表现和方案。
4. **可执行**：方案要落到「每天吃什么、几点睡、做多久、吃几周、怎么复评」。
5. **不编造**：
   - 逐字稿没有的产品、剂量、数据、案例，不要写。
   - 不确定的地方写「课程未展开」或「需进一步核实」。
   - 不虚构文献、期刊、年份、链接。
6. **标注证据等级**（重要）：
   - 【课程观点】魏源老师原话或课程体系说法
   - 【现代医学】主流生理/营养学可解释的部分
   - 【整理】你根据课程做的归纳、推论、方案设计
   - 三者冲突时，保留课程说法但明确写「与主流医学表述不同，对外讲课慎用」。
7. **术语**：统一说「营养素」，不叫「保健品」。
8. **语言**：中文，专业但不学术腔；能直接拿去讲课。Markdown 结构化（本文档是内部知识库，不是对外交付正文，允许标题/表格/加粗）。

## 四、合规底线（每个模块第十二节必须体现）

- 汉本萃全线产品是普通食品/植物饮料，**不是药品，不治病、不替代药物、不做疗效承诺**。
- 不写「根治、治愈、消炎、降压、包治百病、一盒见效、100% 有效」等功效词。
- 不引导问诊、不引导评论区报病情、不留联系方式。
- 涉及结节、肝病、胃病、肾病、甲状腺疾病等，必须写明「需先到医院明确诊断，本方案只做生活方式与营养支持」。
- 课程中缺乏循证依据的说法（如「体温 36.6℃ 与癌症相关」「电磁波导致结节」「肝胆排石」等），只能放在【课程观点】里，并标注「不建议对外直接引用」。

## 五、读逐字稿的方法（省 token、防漏）

- 逐字稿是「长行 + 时间戳」格式，单个文件 5 万—14 万字符。
- **禁止一次性整读**。用 Read 的 `offset` + `limit`，每次 60—80 行（约 2 万—3 万字符），分段推进。
- 先读文件开头的「目录/分集说明」，建立地图，再按集/小节读。
- 读到关键处记下小节名或时间戳，写进第十三节。
- 逐字稿有大量闲聊、跑题、重复。**只提取与健康主题相关的机制、判断、方案、产品、案例**；跑题内容不进入正文，除非它是有用的讲课素材（可放金句）。
- 不要把逐字稿原文大段粘贴进文档；用自己的话重构，原话只用于金句。

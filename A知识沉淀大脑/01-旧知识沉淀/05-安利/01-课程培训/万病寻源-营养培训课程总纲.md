# 万病寻源 · 营养培训课程总纲

> 一句话：病寻到源头是细胞，细胞寻到源头是材料、环境、时间；材料寻到源头是量够不够、肝好不好、路通不通。

---

## 一、课程定位

- 受众：顾客、伙伴、新朋友
- 时长：30–35 分钟（20 页 PPT）
- 目标：用“细胞修复”一个框架，把慢病讲清楚；让听众从“治症状”转到“给材料、给环境、给时间”
- 主线：为什么生病 → 补多少、怎么补 → 为什么先养肝 → 怎么延伸到其他慢病

---

## 二、一条逻辑链

人 → 八大系统 → 器官 → 组织 → 细胞

损伤 > 修复 → 修复端短板：营养匮乏

营养匮乏 → 材料不足 / 吸收损耗 / 分配失衡 / 时间不到

→ 补够量 + 养好肝 + 给时间

→ 按病种选靶点（三高 / 糖尿病 / 脂肪肝 / 肠胃 / 关节 / 免疫）

---

## 三、五个核心结论

1. 病在细胞：魏尔肖《细胞病理学》、《罗宾斯基础病理学》第一章——器官损伤始于细胞分子或结构损伤。
2. 材料六类：结构材料、酶与辅酶、线粒体能量、DNA 修复、自噬清除、ECM/微循环。
3. 量级差：RNI ≠ 修复量；“推荐量是活着，修复量是修好”。
4. 肝是枢纽：加工合成、运输分配、环境治理、时间再生；四接口、五关键。
5. 延伸逻辑：不是按病名吃产品，是按“缺什么、堵在哪、修什么”配营养。

## 五、关键数据与讲法

### 1. 推荐量 ≠ 修复量

- 蛋白质：日常 55–65g → 修复 72–96g，约 1.5×；实际到账常只有 25–27g，缺口 45–70g。
- Omega-3：日常 1–2g → 修复 3–4g，约 2–4×；不是 30–40×（PPT 第 10 页需改）。
- B1/B2：1.4mg → 25–50mg，约 18–36×。
- B6：1.4mg → 30–60mg，约 21–43×。
- 叶酸：400μg → 800–1,000μg，约 2–2.5×。
- B12：2.4μg → 10–20μg，约 4–8×。
- 维 C：200mg → 500–2,000mg，约 2.5–10×。
- 钙：800mg → 800–1,000mg，约 1.0–1.25×；不是 0.2×（PPT 第 10 页需改）。
- 镁：330mg → 500–800mg，约 1.5–2.4×。
- 锌：12.5mg → 30–45mg，约 2.4–3.6×。

### 2. 三重剥削

- 农业空心化：约 -20%
- 烹饪毒化（AGEs）：约 -30%
- 消化无能：约 -20%
- 净结果：标称 100% → 细胞实际到手约 25–30%

### 3. 蛋白质到账示例

- 早餐：10g → 约 5g
- 午餐：25g → 约 10–12g
- 晚餐：20g → 约 10g
- 合计：标称 55g → 实际 25–27g

### 4. 解决方案示例

- 蛋白质：25–27g + 蛋白粉 6 勺 48g → 73–75g（绿）
- Omega-3：约 0g + 组合 1g + 新款 4 粒 2.38g → 2.38g（黄，仍差 3–4g）
- 维 C：<10mg + 组合 200mg + 维 C 3 片 950mg → 约 950mg（绿）
- 维 E：<2mg + 组合自带 70mg → 约 70mg（黄，目标 100–200mg）
- 镁：40–50mg + 组合自带 220mg → 约 270mg（黄，目标 500–800mg）
- B1：<0.5mg + 组合 2.4mg + 维 B 36mg → 约 38.4mg（绿）
- 钙：100–120mg + 组合 700mg + b 285mg → 985mg（绿）

讲法：绿=达标，黄=接近但还差，红=缺口；先补大的，再补小的，按月看，不按天焦虑。

### 5. 安全边界

- 修复量属于临床营养治疗量级，健康人不要照搬。
- B6、锌、维 C、镁都有上限；长期大剂量有风险。
- 肾功能不全、孕产期、儿童、在用药、肝胆疾病、糖尿病、三高人群，必须个体评估。
- 不能替代药物，不能自行停药；急性病、重症、用药期以医生治疗为主。

## 六、护肝五关键与四接口

### 五关键

1. 减负：少酒、慎药、不熬夜、少高糖。
2. 原料：蛋白、B 族、卵磷脂、Omega-3、奶蓟。
3. 通路：足量水、膳食纤维、胆汁、微循环。
4. 节律：23 点前睡，7–8 小时；深睡肝血流可增加约 40%。
5. 情绪运动：疏肝不压抑，快走/八段锦每周 3–5 次。

### 四接口

| 肝脏作用 | 决定什么 | 细胞修复结果 |
|---|---|---|
| 合成效率 | 材料到账率 | 造不出酶和蛋白，原料到不了细胞 |
| 运输分配 | 修复优先级 | 保命分流失衡，补了也送不到 |
| 环境治理 | 修复条件 | 血干净、循环通、炎症低，新细胞才住得下 |
| 更新周期 | 修复时间表 | 肝细胞 5–6 个月换一代，急不得也省不得 |

金句：养肝不是多做一个项目，是给全身修复让路。

## 七、其他慢病延伸

| 慢病类型 | 营养修复重点 | 对应产品方向 |
|---|---|---|
| 三高/心脑血管 | 鱼油降甘油三酯、茶族降胆固醇、钙镁调血压、维 E 护心肌 | 减脂 + Omega-3 + 钙镁 |
| 糖尿病/代谢紊乱 | 维 B 族防神经炎、大蒜片辅控糖、越橘促胰腺修复 | 控糖 + 抗炎 + 胰腺修复 |
| 脂肪肝/肝胆问题 | 奶蓟草 + 蛋白质 + B 族 + 维 C | 解毒 + 修复肝细胞 |
| 肠胃问题 | 膳食纤维 + 益生菌 + 葆蔚饮品 | 肠道菌群 + 黏膜修复 |
| 关节问题 | 钙镁片 + 维 D + 葡萄糖胺 | 骨密度 + 关节润滑 |
| 免疫力低下 | 蛋白粉 + 维 C + 类胡萝卜素 + 大蒜片 | 免疫原料 + 抗氧化 |

讲法：这是方向，不是处方；不能替代降压药、降糖药、降脂药，不能自行停药。

## 八、合规边界

- 营养不替代医疗；急性病、重症、用药期，必须以医生治疗为主。
- 不讲“根治、治愈、包治、百分百有效”；只讲机制、方向、支持。
- 延伸表是方向性建议，不是处方；具体用量按个体评估。
- 对外内容先过 [[F技能库skill/运行规则/01-合规网关.md|01-合规网关]]；内部培训也要守住疾病/疗效表述边界。

## 九、讲课节奏

- 0–3 分钟：开场、自我介绍、抛出“为什么同样三餐不同结果”
- 3–10 分钟：病在细胞、保命分流、身体信号、六类材料、更新时间
- 10–18 分钟：两本书、量级对比、三重剥削、蛋白质到账、解决方案
- 18–25 分钟：肝四作用、四接口、五关键
- 25–30 分钟：其他慢病延伸
- 30–35 分钟：三件事总结、口号、提问

时间不够时：保第 3、6、10、15、18、19 页；其余页用一两句话带过。

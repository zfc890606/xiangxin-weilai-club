# 🎬 自媒体的实操（zfc）

> 教团队做自媒体的完整框架 · 2026-08-02 骨干会整理
> 一句话：**后端守住 + 前端破局，用 AI 把一切都变简单。**

---

## 🧭 一、底层认知：为什么现在做自媒体能成

- **AI 打通了普通人的链接**：web coding（沉浸式编程）出现后，普通人不用懂编程也能用 AI 干活——这是"打通的时刻"。
- **AI 永远不会累**：你解决不了的，让 AI 去解决；只要你的想法清晰，剩下交给它。
- **短视频是破局的唯一出路**：线下找人能做起但吃力，线上自媒体才能拿到公域流量，才有上钻石的希望。
- **10倍增长比2倍增长容易**：要破局就得打破过去的运作体系，不能按老打法重复。

## 🎬 二、短视频本质：两件事

> 一条视频要爆，只做两件事：**创造稀缺性** + **放大情绪**

## 📝 三、短视频创作七件套（我的方法论）

1. **开头：九大人性钩子** — 视觉 / 赚钱 / 恐惧 / 愤怒 / 八卦 / 猎奇 / 高价值 / 炫富 / 热点
2. **人设：反差性人设** — 开头3秒亮身份（医生 / 博士 / 恒大 / 差点挂墙上的经历）
3. **选题：高频痛点** — 评论区是"江湖"，去用户最多的地方偷听；锁定渠道 → 提取问题排行榜 → 评论区挖案例
4. **结构：痛点 → 方案 → 步骤 → 总结**
5. **语言：土 + 比喻 + 重复锤 + 反问逼问** — 不高大上、不说教、不端着
6. **反转 + 权威背书** — 每篇都要有一个反常识；背书体现专业，让 IP 值钱，为转化铺路
7. **表现力：像朋友聊天** — 自然放松，不是讲师式输出；别人听着舒服才愿意听

**结尾固定钩子**：关注我，分享更多有价值的内容。

## 🎯 四、身份定位：两个锚（最难的一环）

- **锚① 身份独有性** — 你独有的特殊经历（互联网记忆点）：例：医生、生物学博士瘦40斤、恒大出身、差点挂墙上
- **锚② 价值锚定** — 你在营养/安利领域的专业证明：证书、深耕年限、上台分享经历

> 互联网上没人认识你 → **要敢于给自己设定身份**，让内心匹配身份。
> 爆款 ≠ 转化：光有经历容易爆，但要有商业价值，专业 IP 必须出来。
> 不同板块讲不同身份：创业板块讲创业经历，营养板块讲专业。

## 📊 五、数据复盘：让脚本方法论持续进化

- 爆款视频数据 → 复制丢给 AI →"帮我分析这条爆款的元素结构"
- 对比没爆的 → 提取差异（如开头3秒）→ 一句话让 AI 把新规则写进脚本方法论
- 实战：14天从 700 粉 → 11,225 粉，4 条 10万+ 播放

## 👥 七、社群运营（守住后端）

- **社群两个核心：IP + 粘性**
  - IP = 专业 → 每周五健康微课堂（AI 工作流一句话生成讲稿 + PPT + 推广文案）
  - 粘性 = 活人感 → 日常晒早餐/蛋白粉、发生活照片；群有魂，不是"新闻联播群"
- **固定栏目**：周二 KOC 分享 + 周五健康微课堂（工作流已建好，一句话搞定）

## 🧠 八、知识沉淀系统（大脑）

- **三个输入**：
  ① 知识卡片（KC）→ 结构化的知识
  ② 洞见卡（DJ）→ 一句话精华
  ③ 参考素材 → 系统课程/书（张海清课件、营养基础班、《营养素参考摄入量》《临床营养学》等，转成 md 入库）
- **触发词："跑流程"** — 碎片知识喂给 AI → 自动生成 KC/DJ、更新选题库
- **原则**：过脑才入库（自己消化过的才有价值）；调出来用一遍又过一遍脑，温故而知新
- 飞书录音：一句话"拉今天的录音跑流程"→ 自动沉淀

## 🚀 九、带团队落地

- 社群排班，大家轮流讲课（AI 让讲课无负担，同时锻炼 IP）

## 📋 十、辅导伙伴实操要点（2026-08-02 点评红利哥视频）

### 内容层面
- **重点信息前置** — 开头就要留住人、别墨迹；不然别人不知道为什么要看你的视频
- **不讲事件，讲问题** — 把客户内心的问题讲出来（如"营养素是不是智商税"）
- **主题明确，一条一题** — 听完要能复述你讲了什么，别贪多
- **删啰嗦** — 反复重复的话删掉
- **讲"为什么"** — 例：不讲政策，讲"营养素为什么不是智商税"（营养缺口、缺乏原材料）
- **跟观众相关** — 群众只关心和自己相关的事（体检报告人人都有，是最好的切入点）

### 表达与镜头
- **表达连贯**：一段话自然地连着讲完，不要一句一句拼凑，否则生硬
- **情绪力**：情绪高低、抑扬顿挫、说话要有力度；**情绪是锁住人听下去的调用**
- **像聊天**：视线别死盯屏幕、自然动；手势放大；笑一笑都可以；有信息高密度推进
- **道具辅助**：前面放桌子，手架在上面更自然
- **侧身对话感**：不一定要正对镜头（头发少可以侧着），对着一个人对话
- **不怕讲错**：讲错了重新讲，可以剪掉

### 运营层面
- **敢于开始，持续迭代** — 懂基础逻辑后就是尝试；拍完跟 AI 复盘
- **评论区经营** — 用心评论、回复评论可提高权重播放（注意账号限制：禁评30天期间没法回）

> 短视频本质就两个：**① 放大情绪 ② 创造稀缺** — 内容和情绪到位，方式不一定要跟张医生一样

## 👀 十一、对标案例：表现力女主播

- 专门培训的女主播，**表现力非常牛**：视频里反复用 **before / after 对比**，效果天差地别
- **矩阵号多账号传播**，传播力极强，全网都能刷到
- 案例：为拍一期视频去面试主播 → 帮人一场直播订单爆了 → 对方几十万请她，她不去
- 启示：**靠能力赚该赚的钱**；表现力 + 对比可视化是她的核心武器

## 🧭 十二、战略清醒：短视频只是其中一块

- 上钻石不容易：**短视频只是一方面，后端团队建设、系统赋能才是关键**
- 一个人能做 **3条线是极限**，6条线钻石必须靠系统赋能
- **转化是难点**：流量来了要能转化
- 知识库本身有很强的信息差 → 多花精力在安利里拿到结果，**跑通才是正道**

## 🎥 十三、辅导实操·画面与声音（2026-08-02 点评森伟视频）

### 声音（先用麦）
- **必须用麦讲 + 降噪** — 不用麦，声音很燥
- 声音是影响数据的因素之一

### 画面与布景
- **背景**：白墙太硬，最好用**窗帘**
- **布景**：人物在中间，左右两边简单装饰（绿植 + 火焰摆件）
- **背景虚化拉到 35 左右** — 画面才有层次感、纵深感
- 灯光、体验感、美感、画面和谐舒服，都要优化

### 表达（不是读稿）
- **别把口播变成专家讲课** — 对方不想听你讲课，不能端着
- 把镜头对方当成朋友：**聊天、谈心、讲故事的味道**
- **不是读稿，而是用自己的话讲一句话** — 提词器的用途在这
- 多一些"真的""天呐""其实"等口水话过渡 — 自然聊天（但不至于太啰嗦）
- 情绪高低、抑扬顿挫 — **情绪是锁住人听下去的调用**

### 复盘心态
- 不断用**用户视角**看自己的作品，自己也要看自己的作品
- 一条视频最终效果由**画面、声音、灯光、内容、表达**综合决定
- **事上练 + 复盘**，就会不断成长进步

> 短视频本质就两个：**① 放大情绪 ② 创造稀缺**

## 🎭 十四、短视频表现力（核心课）

> 来源：[[短视频表现力|张飞·短视频表现力实战课]]（2026-07-12 飞书妙记整理）

### 表现力的本质 = 情绪的表达能力
- 表现力源于演员职业；**普通人本身就是表演大师** — 喝酒、开会、得意、带娃、吵架，日常全是情绪，只是没带到镜头前
- 观众停下来，是**被你的情绪钩住**，不是文案多漂亮
- 画面先有美感/情绪，观众才停留，才有后面的内容

### 提升表现力的两大关键
**① 文案（内容层）：文案不是用来读的，是用来听的**
- 抄爆款：普通人不必自己创造，开头不要改（平台验证过的钩子）
- 熟悉内容：熟能生巧、熟就会自然 → 放松
- 提词器 = 导航仪：扫一眼知道下段讲什么，用自己口语讲，不是逐字念
- 分段拍摄 + 口语词（"比如这样""那么呢"）让对方感觉你在跟他说话

**② 镜头的情绪（表现层）：跟真实的人对话，不是跟镜头说话**
- **「拜小人」技巧**（罗振宇方法）：拍前闭眼刻画真实交流对象（想他长什么样、鼻子里几根毛），请他到面前，跟他聊天
- 情绪呈现：抑扬顿挫、手势配合、关键处停顿、情绪反差（参考疯狂小杨哥）
- 入门 = 跟"小人"对话找交流感；**顶级IP = 跟自己对话，把自己讲感动**

### 拍摄实操
- **画面设置**：九宫格线（眼睛对齐上方线）、镜头调到1倍、背景虚化20-30-40、灯光打亮脸、大饼脸侧一点 + 女生头发放下
- **拍摄流程**：调画面 → 熟悉文案 → 请出小人 → 提词器导航 → 开拍聊天
- **心态**：允许出错（错了重讲，剪辑自动去重）、不必一次过、**批量生产**（一下午30-60条）

### 剪辑要点
- 速度1.1倍、打开降噪、选好封面、套固定模板、BGM音量调至18左右（不盖人声）

### 金句
> 文字不是用来读的，口语化的表达是用来给别人听的。
> 提词器不是读字器，是你大脑的导航仪。
> 你真正的放松，源于你对讲的内容非常熟悉。
> 顶级的IP，他是讲给自己听的，跟自己对话。

> **表现力就两件事：① 文案（让别人听）② 镜头表现力（跟真人对话）**

## 🧠 十五、姜胡说直播笔记：让知识真正跑起来（2026-07-28）

> 讲的是知识库/经验沉淀，正好是第二大脑系统的底层逻辑，也是"八、知识沉淀系统"的印证与升级。

### 核心顺序：先做事，再学习
- 别先问"学什么"，先问"我现在要解决什么"
- 先做事 → 遇到问题 → 找到缺口 → 再学需要的
- 做完复盘三问：**为什么能解决？哪一步最关键？下次能不能复用？**

### AI 用法：不止问答，帮你看盲区
- 持续记录背景/目标/项目/问题/结果 → AI 才真正了解你
- 让它对照过去：这问题以前问过吗？当时建议执行了吗？现在卡的是不是同一种问题？
- **建议可参考，判断自己做——别把 AI 当权威，当陪你拆问题的助手**

### 知识库六层成长（不用一步到位）
1. 单次调用（直接用 AI 干一次活）
2. 让 AI 了解你（背景/目标/常做工作/规则/表达习惯）
3. 分类归档（按项目/主题/场景建目录）
4. 建立索引（Wiki/索引页：每类放哪、解决什么、何时调用）
5. 语义检索/向量检索（资料多了按"意思"找）
6. 原子化/RAG/召回精排（复杂业务拆细、检索筛选组合）

> 标准不是技术多复杂，而是**下次遇到问题能不能快速找到有用的东西**

### 能运行的知识才是资产
- 每段经验想清楚三件事：**解决什么问题？什么情况下调用？调用后产出什么？**
- 例：短视频选题方法 = "最近不知道拍什么"时 → 看评论/咨询高频问题 → 匹配已有经验 → 产出选题和脚本
- 值钱的不是收藏了多少，是沉淀了多少**能反复解决问题的方法**

### 复杂问题 ≠ 一句提示词
- 正确过程：先理解问题 → 调取相关经历/知识/案例 → 找根源 → 再组织回答
- 自我追问：我真正的问题是什么？以前处理过吗？这次怎么验证？
- **把问题问对，比拿到漂亮答案更重要**

### 大模型负责思考，流程负责稳定
- AI 会跑偏遗漏；固定流程承担检查/提醒/记录/权限/回溯
- 最值得练的能力：把工具放进真实工作，和记录、方法、流程连起来
- **从小事开始：跑一次，修一次，再跑再修——系统是长出来的，不是搭出来的**

### 落地动作（写给起步的伙伴）
- 从这周反复在做的一件事开始（内容输出/客户沟通/直播复盘/卡住的问题）
- 每次做完记三句话：**遇到什么问题？怎么解决的？下次该怎么做？**
- 先连续留 10 条真实记录 → 交给 AI 分类、提炼、复用

## 🧭 十九、做好自媒体的本质：IP核心 × 市场理解（2026-08-07 录音）

> 来源：飞书录音 · 已拆卡 [[A知识沉淀大脑/00-新知识入库/洞见卡/DJ-创业-077-做好自媒体缺一不可：IP核心×市场理解]] / [[A知识沉淀大脑/00-新知识入库/知识卡片/KC-创业-038-自媒体双引擎：IP核心×市场理解]]

### 一句话
> **做好自媒体 = 两个点缺一不可：① 你有"自己的东西"（IP核心 = 成长中认知拔高的点 = 选题金矿）② 你懂自媒体语言 + 调研市场（怎么表达才打动观众）。**

### 两个失败典型
- **很专业，但不懂市场** → 内容再对，表达打动不了观众，跑不出去
- **懂市场，但没有自己的IP核心** → 会追热点会表达，但没自己的东西，立不住

### 怎么落地
1. **建"认知拔高点"记录本**：成长中让你脑袋打开的点，随手记 → 这就是选题金矿
2. **每个选题过两道检**：① 这是我的东西吗（IP核心）？② 用自媒体语言怎么表达、哪个点打动观众（市场）？
3. **先调研再写稿**：看当下同领域爆款怎么表达、评论区问什么——不自嗨式写稿
4. **复盘归因**：数据不好先判断是"没根"还是"没翅膀"，对症下药

### 📼 录音原文（整理版）
> 想到一个点，就在做自媒体的过程当中。第一个，你在你成长的过程当中，让你认知拔高的、让你这个脑袋打开的那个点，你要把它记录下来——这个是你一个很好的选题。
>
> 但是这个选题呢？你要怎么去拍呢？这个就要懂自媒体的逻辑，就像你要懂自媒体的语言。这个呢，需要你对当下这个时代的自媒体做一个调研——怎么去表达、哪个点能够打动观众。但是呢，这个选题，这个真正让你打开认知的一个点，是非常重要。
>
> 其实我觉得，要做好自媒体的本质：第一个，你自己的，你得有你的东西；第二个，对自媒体的理解、调研市场。这才是一个 IP 操盘手应该核心关注的两个点。就是我们很多人，他很专业，但是对市场他不懂，那他不一定能够跑得出去。那很多人呢，他懂（市场），但是他没有自己的 IP 核心。缺一不可。

## 🚀 二十、10倍增长 × 自媒体选择（《为什么10倍增长比2倍更容易》启示 2026-08-11）

> 来源：[[A知识沉淀大脑/01-旧知识沉淀/03-书籍/为什么10倍增长比2倍更容易/为什么10倍增长比2倍更容易]] · 作者丹·苏利文/本杰明·哈迪 · 已拆洞见卡 [[A知识沉淀大脑/00-新知识入库/洞见卡/DJ-创业-076-10倍增长比2倍增长容易：破局要打破旧体系]]

### 一句话
> **要真正有 10 倍增长，关键在选择媒体/渠道（换系统），而不是把老打法优化 2 倍（更努力）。** 自媒体就是我们选的"10x 系统"——线上公域流量让别人来找你，取代"线下一个个找人"的 2x 打法。

### 为什么"选择媒体"就是 10x 的核心杠杆

| 对比 | 2x 打法（老系统） | 10x 打法（换媒体/换系统） |
|------|------------------|--------------------------|
| 渠道 | 线下找人、一对一拜访（一个对一个） | **短视频/视频号/公众号 → 公域流量（一个对一万个）** |
| 工具 | 人肉、口传、靠体力 | **AI 内容系统 + 知识库 → 自动生产、自动沉淀** |
| 身份 | 推销员（追着人讲） | **AI营养师（用内容把人吸过来）** |
| 资源 | 摊薄：什么都做 | **聚焦：只做医生营养科普这一条高杠杆线** |

- **判断信号**：当你又冒出"再努力一点、再多跑几个"的念头时，停下来问——**是不是该换个系统（换媒体/换打法），而不是更努力？**
- 书里原话逻辑：问"业绩怎么涨 10%"答案有无数个（会内卷），问"业绩怎么涨 10 倍"答案只有一个——**换赛道、换打法、换身份**。

### 书里最该带进自媒体的 5 个思维

1. **10 倍目标是最好的过滤器** — 选题/内容方向太多会瘫痪；给自己定"帮普通人成为 AI营养师"这一个 10 倍目标，很多选题自动被过滤掉
2. **独特能力 = 你的 20%** — 张医生的独特能力 = 医生专业 × AI × 安利 = **AI营养师**。只做这个身份下的内容，其余交给 AI/团队
3. **注意力是最稀缺的资源** — 比时间更贵。同时开太多线=摊薄注意力；聚焦 20% 高杠杆动作（内容+AI系统+核心伙伴）
4. **质量 10x 有指数效应** — MrBeast 说内容质量提升 10%，播放可能翻 4-10 倍。**与其多拍 10 条平庸的，不如把 1 条打磨到爆**（四两拨千斤）
5. **复盘用"进展"（Gain），不活在"差距"（Gap）** — 用现在的自己对比过去的自己（700粉→11,225粉），别拿自己和理想中的大 V 比（永远够不着、只会内耗）

### 三个落地动作（直接套用）

- **① 换系统检查**：每次卡瓶颈，先写"我在老体系里还能再挤多少？"——如果没多少，立刻换打法（换媒体/换 AI 工具/换身份表达），而不是加班
- **② 给思维留白**：每周至少留一段不工作的"自由日/留白时间"，只思考方向——书里叫 150 天自由日，高质量恢复=高质量输出
- **③ Who Not How（成事在人）**：不问我怎么做，问谁/什么系统帮我做——**AI 就是你的第一个"Who"，知识库就是你的"Who"，团队就是你的"Who"**。"跑流程"就是让系统替你干 80% 的活，你只做独特能力的 20%

### 一句话收尾
> **10x 不是更努力，是换系统。** 我们选对了媒体（短视频+公域+AI），剩下的就是聚焦 20%、砍掉 80%、让系统替你跑。

## 🧭 二十三、IP穿越周期：真诚 × 作品力 × 底线 × 人性光辉（2026-08-24 认知整理）

> 来源：自媒体认知文章整理
> 一句话：**未来3年，网红/博主会烂大街，最稀缺的不是会拍视频的人，而是值得被长期信任的人。能穿越周期的 IP = 真诚不示弱 × 真作品力 × 底线比利益硬 × 人性光辉。**

### 🌊 时代判断：为什么旧打法会失效

- **旧的营销手段会逐渐失效**：追热点、研究算法、编故事、制造焦虑
- **用户已经形成天然不信任**：快消项目割了一轮又一轮，知识付费买了一茬又一茬，什么套路都见过
- **未来最稀缺的不是会拍视频的人**，而是**一个值得被长期信任的人**

### ✅ 穿越周期的四条铁律

**① 真诚，但不要示弱 — 示弱的人设是 IP 的毒药**
- 反例："我是全城最傻的餐饮老板""三年前我差点从这里跳下去"——看似真实，实则是在向用户索取同情
- 观众不需要一个比自己更脆弱的人，他们需要**能带领自己走出去的人**
- 可以讲低谷，但必须给出力量；可以展示伤疤，但最终要拿出方法和结果

**② 必须拥有真正的作品力和审美**
- 审美 ≠ 画面好看，而是**对内容、人性和时代的判断**
- 灵魂三问：① 离开投流，还能不能获得流量？② 不追热点，能不能自己制造话题？③ 换一个零粉丝的新号，能不能重新做起来？
- 影响力完全依赖投流和资源 = **一个昂贵的广告位**，预算一停流量就消失
- 真正的 IP，哪怕账号被清零，也能从头再来

**③ 底线必须比利益更硬**
- 不卖自己都不相信的产品，不承诺自己交付不了的结果，不利用别人的焦虑收割别人的积蓄
- 真正的商业道德，不是没有诱惑时表现善良，而是**巨大利益摆在面前时，依然知道什么不能碰**
- 有些钱赚了，这辈子都洗不干净

**④ 身上要有人性的光辉**
- 判断标准很简单：能操纵情绪时，选择**唤醒**而不是煽动；能制造焦虑时，选择**给人答案**；拥有影响力后，不把普通人当流量/数据/韭菜，而是希望他们因为遇见你，人生变得更好一点
- 顶级 IP 不是研究如何从一群人身上拿走更多，而是思考拥有流量之后，能为时代留下什么

### ⚔️ 两种打法的分野：投流派 vs 作品力派

| 对比 | 传统投流打法 | 作品力打法 |
|------|-------------|-----------|
| 研究什么 | 把0分的人教到60分、把60分的人提到90分 | 把90分的内容推到100，创造现象级账号 |
| 依赖 | 投流、资源、预算 | 内容本身、作品力、审美 |
| 停止投流 | 流量消失 | 依然能跑 |
| 核心资产 | 广告位 | 值得被信任的人 |

- **终极检验**：一个人拥有100分能力之后，能不能依然守住底线
- 流量可以训练，作品力可以提高，但**一个人的底色很难改变**
- 有底线、有良知的人越多，行业才会越干净

## ⚡ 二十七、AI 会话 Token 优化指南（团队版）

> 团队参考 — 如何优化各自 AI 配置的 tokens 消耗 · 创建 2026-08-28 / 更新 2026-08-29
> **30 秒看懂**：AI 每次新对话都会把「指令文件」（如 CLAUDE.md）完整读一遍，文件越大越费钱。**把不常用的大段细节移到"用到才读"的文件里，指令文件保持精简 = 每次对话都省钱，规则一条不丢。** 本指南教你照做。

### 27.1 为什么 tokens 值得优化？

| 概念 | 白话解释 |
|:---|:---|
| **Token** | AI 计费的最小单位（约 0.7 个汉字 ≈ 1 token） |
| **每次新对话固定成本** | 系统自动读取指令文件（CLAUDE.md 等），**无论你问什么，这份文件都完整读一遍** |
| **对话中每条消息** | 只读增量 + 累积上下文，与指令文件长短无关 |
| **结论** | 指令文件越短 → **每个新对话固定省一笔**；每天开几个会话，长期累积很可观 |

### 27.4 可直接复制的「优化提示词」

> **用法**：把下面这段发给你的 AI 助手（任何模型），让它帮你优化自己的指令文件。**改你自己的文件前记得先备份。**

```text
请帮我优化我的 AI 指令文件（如 CLAUDE.md / AGENTS.md / 系统提示词）以节省 tokens。

【背景】该文件每次新对话都会被完整读取，文件越大每次对话成本越高。
【目标】在【不丢失任何规则/能力】的前提下，尽量压缩文件体积（目标：行数减少 30%+）。
【方法】
1. 先备份原文件（如 .claude/backup/xxx.bak.日期）
2. 按以下 8 类冗余逐段扫描并优化：
   ① 与系统自动注入重复的内容（技能列表等）→ 删除留指针
   ② 同一规则多处重复 → 只留一处

4. 完成后输出对比报告：行数/字符数/估算 tokens 前后变化 + 修改清单
5. 保留所有【强制/红线】类规则原文，只改表述不删含义
```

### 27.5 量化验证方法（怎么算 tokens）

没有精确工具时用估算公式（误差 ±10%，相对比例稳定）：

```text
估算 tokens ≈ 中文字数 × 1.5 + 英文单词数 × 1.3 + 其他字符(标点/空格) × 0.35
```

bash 一条命令（Linux/Git Bash）：

```bash
f=你的文件.md
cjk=$(grep -o '[一-龥]' "$f" | wc -l)
words=$(tr -c 'A-Za-z0-9' ' ' < "$f" | tr -s ' ' | wc -w)
chars=$(wc -m < "$f")
other=$((chars - cjk - words*6)); [ $other -lt 0 ] && other=0
awk -v c="$cjk" -v w="$words" -v o="$other" 'BEGIN{printf "估算tokens≈%.0f\n", c*1.5 + w*1.3 + o*0.35}'
```

- ⚠️ **备份先行**：任何优化前先 `cp` 备份，可随时回滚
- ⚠️ **不删独有规则**：下沉 ≠ 删除；指针指向的文件必须真实存在

## 🧭 三十六、从广告营销到内容营销：没有内容就没有传播，没有 IP 就留不住人（2026-09-23 认知整理）

> 来源：张医生原话
> **原话**：从广告营销到内容营销。传统广告营销模式已经崩溃，未来，没有内容就没有传播，没有IP就不能留住用户。
> **一句话**：广告是**租**注意力，内容+IP 是**存**资产——**内容解决"被看见"，IP 解决"被留下"。**

### 🌊 判断：崩的不是广告效果，是广告赖以成立的前提

- 广告的机制是**打断**：花钱买断用户三秒注意力。它靠三个前提活着——① 媒介集中（央视/报纸/货架）② 用户没有免疫力 ③ 渠道能给信任背书。
- 今天三个前提全塌了：媒介碎成千万个 → 注意力被分流，单位成本一路涨；用户被教育了十几年 → "你越精准，我越知道你想卖"；**背书的载体从机构换成了人** → 用户信的是"谁说的"，不是"在哪说的"。
- 结果：广告从**投资**变成**租金**。停投即归零，投得越久越不敢停——这正是本册二十三节说的"**一个昂贵的广告位**"。

### 🧮 两个命门（把原话拆开看）

**① 没有内容，就没有传播**
- 传播的介质变了：过去靠渠道，现在靠**人的转发**。转发的唯一前提是——这东西值得我说给别人听（社交货币）。内容 = 可被复述、可被转发的理由。
- 在推荐算法里，内容是唯一的门票：算法按完播/互动/留存分配流量，不认你花多少钱。

**② 没有 IP，就留不住用户**
- 分工不同：**内容负责拉新（被看见），IP 负责留存（被记住、被信任、被反复选择）**。
- 产品会被比价，人不会被比价。IP = 信任的压缩包 + 用户决策的捷径。
- 没有 IP 的账号只能靠不断投流、不断促销续命；一停，用户连你是谁都想不起来。

### 🔁 观念对撞表（可直接讲给伙伴听）

| 对比 | 广告营销（旧） | 内容营销（新） |
|---|---|---|
| 花钱买到什么 | 注意力（一次性消耗） | 信任（可复利） |
| 流量归属 | 租的，停投即失 | 存的，长在人身上 |
| 用户记住谁 | 记住一句广告语 | 记住一个人（IP） |
| 竞争维度 | 谁预算多 | 谁内容好、谁更值得信 |
| 终极检验 | 停投流、换新号，还剩什么？ | 账号清零也能重做（见二十三节·灵魂三问） |

### 🎯 落地到我们的三条

1. **产能交给 AI 大脑**：一鱼多吃（一份功夫拆多平台分发），内容不再是"想不出来"，而是"发不完"——这是 AI营养师最硬的差异化。
2. **留存交给私域 IP**：短视频是内容的入口，朋友圈是内容的存钱罐。客户加的应该是"张医生这个人"，不是"某个产品号"。
3. **不跟人拼预算，只跟自己拼内容**：近10年临床 · 安利创业近10年 · 亏30多万，这些真实经历别人抄不走。**钱的杠杆有限，认知和作品的杠杆没有上限。**

### 📼 金句收藏

> "广告是租注意力，内容和 IP 才是存下来的资产。"
> "没有内容就没有传播，没有 IP 就留不住用户。"
> "产品会被比价，人不会。"
> "停投就归零的，不叫生意，那叫广告位。"

## 🧭 三十七、打造五星级朋友圈与个人 IP：IP 的本质不是专业，是能量（2026-09-27 内训课整理）

> 来源：张医生内训课《打造五星级朋友圈与个人 IP》（团队内训 · 私域内部）
> **一句话**：**IP 的本质不是专业，是能量**——新人 2–3 个月就能立住；用 **T 字型朋友圈**把能量呈现出来；发圈**只发结果、不发答案**（做营销，不做推销）。

### 🚀 一、新人 2–3 个月立住 IP：三步

| 步骤 | 做什么 | 关键 |
|---|---|---|
| ① 从学习开始 | 真实记录在学、在成长的过程（学基础班/考证/看书，哪点打动了你） | **别一上来就说"我很厉害"**——IP 的起点是"正在认真学习的人" |
| ② 学习者 → 拿结果 | 自己的效果 + 考证 + 上舞台（社群讲一课、线下分享一次） | 光"一直在学"撑不起人设，要有实践结果做支点 |
| ③ 人设成立 | 名片/标签/专业度整体到位 | **水到渠成**——别人看着你一步步走过来，自然信 |

> 核心：**别人相信的不是一个结果，而是一段旅程。** 全程真实记录，2–3 个月即可。

### 🎭 二、高价值 IP 的本质：能量

- **最根本的区别：谁影响谁——取决于能量高低。** 你能量更高，能量就会传导、影响对方。
- 张医生北京的例子：第一次见面的吴医生、罗博士，当天就开卡——不是因为他专业（专业的人很多），而是**朋友圈的长期打造让"这个人"先被认可了**。
- 能量从哪来？**恰恰是从困难里爬起来、跟命运抗争、做高能量的事**（例：2015 年 26 岁投 30 万开奶茶店；2020 年月入 3 万辞职转大健康）——陌生人看到的是勇气、魄力、敢折腾。
- **当下越困难，越是提升能量的机会。** 维度一高，做任何事都变简单。

### 📱 三、T 字型朋友圈（高能量朋友圈的结构）

| 笔画 | 定位 | 发什么 | 给什么价值 |
|---|---|---|---|
| **横 一** | 大杂家 | 真实生活：感悟、家庭、孩子、运动、学习、旅行、成长 | **情绪价值**（温度、共鸣、吸引） |
| **竖 丨** | 小专家 | 小切口的专业：你的专业、帮了谁、证书、陪跑客户 | **功能价值**（信任、成交） |

- 一句话：**既做杂家，又做专家。**
- ⚠️ 误区：做大健康就天天只发案例/知识/海报，忘了生活——**你要去热爱生活**。
- ⚠️ 不要发：负能量、吐槽、八卦、是非；也不要发模板化健康简报——**一定要加上自己的话**。

### 🔑 四、发圈铁律：做营销，不做推销

> **营销 = 制造"有问题的结果"——只发结果，不发答案。**

- ✅ 营销：只发"这个人好了/改善了"，**不说怎么做到的** → 对方会追问"方案是什么？"（制造期待）
- ❌ 推销：把方案、产品、配比全盘托出 → 能看出答案的都叫广告，**广告没人看**

### 🖼 五、朋友圈门面：五件套

**背景图 · 简介 · 名字 · 头像 · 置顶**（置顶朋友圈 / 置顶视频）
- 置顶放：**高光时刻 + 个人价值 + 帮别人解决问题的成果**。
- 其他可发：正能量的圈子、大场面、优质圈子——让别人看到你在成长、跟优秀的人在一起，**这本身就在提高能量**。

### 🧭 六、为什么基础工作要做在前面

- 朋友圈先做好，再做线下链接，**效能非常高**——因为别人已经"在朋友圈看过你"了。

## 🎯 四十、老板IP 找选题：从业务里「抄原话 · 补场景 · 给判断」（2026-09-29 认知整理）

> 来源：某短视频博主观点（张医生深有体会）+ 张医生本人爆款验证
> **一句话**：做老板 IP 比做网红容易——**你天天泡在一线，客户的原话就是你的选题库**。选题占 80%；选对了，拍得差也是好视频。
> **张医生的体感**："视频说的非常到位——在用户问题里面找选题，解决用户的问题，就是一个好视频。"

### 🎯 1. 先确立一个铁律：80% 是选题

- **选题选对了**：哪怕你拍得差、讲得差、说得差，它依然是一条好视频（画质、表现力到位就更好）。
- **选题选错了**：你把张艺谋请来拍、拿最好的相机，也是**纸上雕花**。
- **所以**：不要拍那些"你以为好的、不痛不痒的"——**市场不关心你讲什么，数据当然差**。

### 🧭 2. 老板 IP 比网红多的一样东西：业务现场

- 网红找选题靠**外部热点**；老板找选题靠**自己的业务**——这是老板跑得更快的根本原因。
- 素材就三个地方：**客户的吐槽原话 · 差评 · 面对面的吐槽**。
- **关键动作**：在客户那句吐槽上，**补上"他是在什么场景下说的、说之前遇到了什么"**——你就有了解释的空间；你把这个问题用短视频解答了，这就是一条视频，而那句话就是这条视频的**选题**。

### 🛠 3. 三步找题法（可直接教给伙伴）

| 步骤 | 做什么 | 例子（"你家为什么比别人贵这么多"） |
|---|---|---|
| ① 抄原话 | 把客户吐槽/差评的**原话**直接拎出来当标题 | 客户说："你家为什么比别人家贵这么多？" |
| ② 补场景 | 还原**在哪说的、什么心情、什么空间、为什么说** | "前两天我巡店，一位穿得很漂亮的小姐姐体验完服务，说了这句话。" |
| ③ 给判断 | 讲出**你的经营理念**——人设就是这么立起来的 | 讲你的成本观/品质观 → 吸引认同你价值观的人 |

**"补场景"的本质 = 把客户那句问题讲成一个故事。**

### 🗣 4. 经典原话范本（"贵与不贵"这类题怎么讲）

> "我不怕你比价格，我就怕你只比价格不比品质。低价的背后，一定有你不知道的省法。同样一副墨镜，85 和 25，送给你你选 85；但今天要是让你自己掏钱买，你就想买 25。**奥拓的价格永远买不到奥迪。决定价格的唯一标准叫「形同而质不同」。市场没有标准价，只有合理价——没有价格的支撑，哪有品质的保障。**"

- 这类"客户嫌贵"的原话，**火锅店、眼镜店、任何一种服务都会遇到**——所以它是一道**通用选题**。
- 加一个场景、讲一段你的经营理念，一条视频就出来了。

### 🚀 5. 张医生的爆款验证：这 4 条全是"客户问得最多的问题"

| 爆款选题 | 对应的一线问题 | 性质 |
|---|---|---|
| 1. 营养素 ≠ 保健品 | 客户分不清概念 | 认知纠偏 |
| 2. 营养素为什么能调理身体 | 客户问"凭什么有用" | 原理科普 |
| 3. 医生不懂营养 | 客户信医院不信营养 | 身份/信源 |
| 4. 营养素是不是智商税 | 客户怕花冤枉钱 | 破除偏见 |

> ✅ **这些选题就是市场前线**——它们是**客户做得最多的问题**。你把客户的问题用短视频解决了，就是一个好选题。
> ⚠️ **合规提醒**：第 2 条这类涉及**疾病/功效落点**的题，写稿前必须先过 [[F技能库skill/运行规则/01-合规网关|0号闸门·无认证期选题落点判定]]；落点属疾病/功效/指标层的，换题不写稿。

### 🔁 6. 为什么"给判断"能立人设

- 老板给出判断时，会吸引一波**认同你价值观**的人，同时也会吸引一波**反对你、骂你**的人。
- **但在互联网上，骂你不重要**——骂你还帮你增加流量、增加评论。
- **记住**：在互联网时代，我们做的是**让爱你的人更爱你**，而不是**让黑你的人变成你的粉丝**。

### 🎯 7. 落地到我们的三条

1. **建立"客户原话库"**：把客户吐槽、差评、面对面问题随手记下来（进 [[B自媒体大脑/00-选题库/评论区选题池|评论区选题池]] / 痛点记录），**每条都是一颗选题种子**。
2. **一次拍完"原话+场景+判断"**：不追热点、不自嗨，只回答客户真问过的问题。
3. **越到前线，越懂市场**：泡一线 → 懂市场 → 会做短视频，这是一条正向循环；坐在屋里想选题，只会"不痛不痒"。

> "选题选对了，拍得差也是好视频；选题选错了，张艺谋来拍也是纸上雕花。"
> "80% 是选题。"
> "在用户问题里面找选题，解决用户的问题，就是一个好视频。"
> "决定价格的唯一标准，叫做形同而质不同。"
> "越到前线，越懂市场；越懂市场，就越会做好短视频。"
> "让爱你的人更爱你，而不是让黑你的人变成你的粉丝。"

## 🎬 四十一、拆解陈晶 883 条视频：从「爆款博主」到「短视频营销获客系统」的 5 个发现（2026-09-29 认知整理）

> 来源：某博主拆解清华陈晶 2022–2026 全部 883 条视频的整理（张医生深有体会）
> **一句话**：陈晶真正厉害的不是会做爆款，而是**花几年时间把一个账号做成了一整套短视频营销获客系统**——只学"反认知开头 / 532 结构 / 该拍长视频"这些表面套路，**连他 30% 都没学到**。
> **张医生的体感**：拆的时候**不盯哪条爆了、点赞多少**，只盯一件事——**他的内容到底是怎么进入客户、进入业务、进入成交的**。

### 🔍 一、真正负责流量的内容，不是你以为的那些干货

- **现象**：账号里几十万赞的是**教育、人与人的关系**这类破圈话题；而"短视频怎么拍、IP 怎么做"这类专业内容只有一两千赞——**但收藏和转发数据反而很好**。
- **结论**：商业 IP 需要**两类完全不同的内容**——一类负责**把人带进来**（破圈流量），一类负责**让进来的人越来越相信你**（专业信任）。**两类弄混，账号就特别容易做死。**
- **企业为什么做一年还是几百播放**：把 100 条视频拍成了一本**"产品说明书"**——做财税天天讲财税、做机械天天讲参数、做装修天天讲施工工艺。讲得很专业，但**没人看**。
- ⭐ **核心翻案：真正应该垂直的不一定是内容，而是人群。**
  - 想要老板客户 → 获客、销售团队、现金流管理、AI —— **这些都可以讲**，因为最后被吸引来的是**同一拨人**。
  - 别再问"我这个行业还有什么可以拍的"（问这句就说明**把问题看窄了**）；真正该问的是：**"除了我的产品以外，他还在为什么事情焦虑？"**——这是两套完全不同的选题逻辑。

### 🧭 二、主页是一条用户转化路径（532 结构的真义）

- 陈晶总结的 **532 = 50% 出圈 · 30% 人设信任 · 20% 产品转化**。
- ❌ **学浅了的样子**：理解成"这周拍 10 条，5 条出圈 3 条人设 2 条产品"——**这只是比例问题**。
- ✅ **真义**：它解决的是**一个陌生客户从第一次刷到你、到愿意付费，中间到底经历了什么**。三句话版本：

| 内容类型 | 回答的问题 |
|---|---|
| 流量内容 | **为什么刷到你** |
| 人设内容 | **为什么相信你** |
| 产品内容 | **为什么最后找你买** |

- **三种做死的账号**：
  1. 爆款几十万播放，用户刷完**连你是干嘛的都不知道**；
  2. 天天讲专业，用户觉得"这老师懂得挺多"，但**不知道为什么要花几万块钱找你**；
  3. 100 条里 80 条广告（公司成立多少年、设备多先进、服务过多少客户）——**用户根本不想看**。
- ⭐ **记住这个词：一个真正能获客的账号，本质上不是一堆视频——整个主页就是一个营销漏斗。**

### ✍️ 三、"叙文案化"（去文案化）：稿子整理观点，不生产观点

- 他早期也干过**很多人现在还在干的事**：把自己关在酒店**一口气写 30 条逐字稿**，然后坐在镜头前**一条一条念**。
- 后来换成**聊天**：吃饭时聊、在办公室聊、别人问他问题他来回答——**变成在业务场景里直接讲话**。
- 结果：画面**没那么精致了**、每句话**没那么"有水平"了**，但**人设越来越真实**。
- ⭐ **对老板 IP 尤其重要**：**稿子的作用是整理你的观点，而不是替你产生观点。**
- ⚠️ **AI 时代的坑**：有了 AI 之后特别容易——**稿子越来越漂亮，但老板越来越不像自己**。
- 结论：老板 IP 竞争到后面，**拼的不是谁的文章漂亮，而是谁真的有东西可以讲**。

### ⏱ 四、视频越来越长，但变的不是时长，是内容层级

| 年份 | 平均时长 |
|---|---|
| 2022 | 约 31 秒 |
| 2023 | 约 47 秒 |
| 2024 | 约 53 秒 |
| 2025 | 超过 1 分钟 |
| 2026 | 约 6 分钟 |

- ❌ **只看表面**会得出"现在开始要拍长视频了"——**又看错了**。
- ✅ **真正发生的变化：从教 what（怎么做）→ 教 why（为什么）。**
  - **what（执行层）**：开头怎么写、标题怎么起、视频怎么剪、字幕怎么加 → 关心的只有**运营、员工、操盘手**。
  - **why（决策层）**：为什么要做短视频、该不该做老板 IP、行业到底适不适合、要投多少钱、对**未来三年增长**有没有价值、不做会失去什么、做错的风险是什么 → **这才是老板真正关心的**。
- ⭐ **不是平台把用户推错了，而是你一开口就决定了会有谁留下来看这段视频。**
- **数据现象**：他的**长视频点赞不一定最高，但收藏、转发明显更好**——因为浅内容让用户"听得爽"；深度内容让用户觉得**"这个我得留着发给合伙人 / 运营负责人看，这个人值得我继续关注"**。这才是**高客单生意**真正想要的结果。
- ⚠️ **反对一句话**："现在是长视频时代，所以要把视频做得越来越长"——**时长只是表面**。**1 分钟能讲完，一定不要拖到 8 分钟，那不叫深度，叫啰嗦。**
- ⭐ **真正的深度 = 同样一个问题，你能不能想到别人没有想到的层次。**

### 🔄 五、越到后面不再"想选题"——业务自己产生内容

- 他的内容来源已经**不是选题库**：客户咨询的问题、直播间里的问题、交付过程中出现的问题、员工的问题、客户的案例、售后投诉、公司内部发生的事、看到某个同行说了个观点特别想反驳……
- **反常识现象**：很多人拍几十条就觉得**没内容可拍了**；他拍了 1000 多条还是有很多东西可以讲——因为他**已经不是靠选题库活着，而是靠业务活着**（只要还在接触客户、还在经营公司、还在做决策、还在踩坑，素材就源源不断）。
- ⭐ **成熟的企业内容生产系统，是一个循环**：

> **业务产生素材 → 素材做成内容 → 内容带来客户 → 客户产生交付 → 新的交付再产生新的素材与内容**

- ❌ **大部分企业**：这些事**发生以后就消失了**，没有被提炼成内容；运营只能坐在屋里冥思苦想今天该拍什么。
- **AI 该干嘛**：不是让 AI 每天帮老板写 100 个观点——**AI 的观点是从哪里来的？**（答案仍在业务里。）

> ⚠️ 原文结尾处被截断（"……AI 的观点是从哪里来的？它"），此处按上文逻辑补全为"来自业务"，待原话补全后可校正。

## 🧭 四十二、个人品牌是最大的复利：IP = 可识别的你 = 低价获客的永久资产（2026-10-03 认知整理）

> 来源：短视频/直播观点转述（张医生深有体会）
> **一句话**：IP 不是玄学，它有定义——**IP = 可识别的你**。它干两件事：把"看过你一次"变"记住你"，把"记住你"变"愿意跟你走"；做到之后，**同样的内容，你的获客成本永远比别人低**。所以**个人品牌 = 低价获客的永久资产**。
> **张医生的体感**："不要卷价格，不要卷任何跟价格有关的东西，卷品牌。"

### 🧭 1. 先给 IP 一个定义：可识别的你

- 大多数人天天在说 IP，**却从没定义过它**。一句话定义：**IP = 可识别的你**。
- 它解决的是"**识别**"问题：别人一刷到就知道"哎，这不是他吗？"
- 两个动作：**把"看过一次"变成"记住你"；把"记住你"变成"愿意跟你走"。**

### 🧮 2. 为什么 IP = 低价获客：稳定的风格 + 价值锚点

- 当你形成**稳定的风格**和**价值锚点**，同样一条内容，你的获客成本**永远比别人低，而且低得多**。
- 反过来看：你天天卷价格、买流量、比便宜——**不是你不够努力，是没有人记得住你**。客户记不住你，就只剩下一个判断标准：价格。
- **价格是唯一没有底线的战场**——你永远会遇到比你更便宜的。这就是"不被记住 → 只能比价 → 越比越亏 → 更不敢停"的死循环。
- 结论金句：**个人品牌 = 低价获客的永久资产。**

### 🚀 3. AI 红利：一个人 = 一个小团队

- 以前做内容要脚本、拍摄、剪辑、设计、分发、复盘——**一个人根本扛不动**。
- 现在 AI 把每一环都提速：写标题、改脚本、做分镜、生 BGM、做封面、扒热门标签。
- 所以 **AI 第一次让普通人真有机会去做一家"一人公司"**（呼应 [[总控台/自媒体实操zfc|二十五、AI 大脑：把方法论驯化成创作系统]] · [[总控台/自媒体实操zfc|三十七、打造五星级朋友圈与个人 IP]]）。

### 🎯 4. 落地到我们的三条

1. **不卷价格，卷品牌**：所有跟价格有关的竞争都是坑；把力气花在"让人记住你这个人"上。
2. **不买流量，做内容**：用 AI 把内容效率拉满，用内容攒"低价流量护城河"（呼应 [[总控台/自媒体实操zfc|三十六、从广告营销到内容营销]]）。
3. **给 IP 建"锚"**：稳定风格 + 稳定价值锚点——每条圈、每条视频都是同一把声音、同一套判断，别今天一个样、明天一个样。

### 📼 金句收藏

> "IP，就是可识别的你。"
> "把看过一次变成记住你，把记住你变成愿意跟你走。"
> "你不被记住，就只能被比价。"
> "不要卷价格，卷品牌。"
> "个人品牌，是一份低价获客的永久资产。"
> "别买流量去做内容，用 AI 把效率拉满，去建你自己的低价流量护城河。"

## 🧭 四十三、2026-10-07 批量沉淀：180/169 两条观念爆款 → 风格系统 v1.43 四条新规（数据驱动）

> 来源：两条新录数据的逐条分析（[[B自媒体大脑/01-视频号创作/交付脚本库/爆款素材库/025-好好吃食物就可以了（爆款分析）|025 / script-180]] · [[B自媒体大脑/01-视频号创作/交付脚本库/爆款素材库/026-医生说没问题营养师说你缺了很久（爆款分析）|026 / script-169]]）→ 一次性织入写稿现场 [[B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统|视频号脚本风格系统]] **v1.43（2026-10-07）**。
> **一句话**：这次不是加新玩法，是**把两条实测数据反哺进"选题 → 写作 → 转发"三层**，让风格系统自动带着新判据走。

### 🎯 1. 选题层 ·「靶子可指认度」+「靶子三级」（据 180）

- 靶子**不只是"具体商品"，也可以是"一句人人说过的全民共识话"**——而且这一类**更能拉评论**。
- **靶子三级**：① **一句人人说过的全民共识话**（观众能原样复述、再反驳）→ 评论**当场就爆**；② 具体商品／价位／人物；③ **一种处境／身份**（流量高，但评论"迟到"）。
- 证据：180「好好吃食物就行了」→ 评论 **2.59‰（全库第四）**；145「穷 vs 富」（处境）→ 1.50‰（且是长尾才补上）。
- 落点：爆款公式「选题」要素新增「拆一句全民共识话」；选题卡第 ⑧ 项升级为「靶子可指认度」+ 新增「🎯 靶子三级」小节。
- **题源启示**：「一句全民老话／全民共识」＝「业务现场原话」（[[总控台/自媒体实操zfc|四十、老板IP 找选题]]）之外**又一个现成的高天花板题源**。

### 🏷️ 2. 写作层 ·「命名概念」＝观念类涨粉开关（据 180）

- **给一个抽象道理"起一个名字"**（如 180 的「到账率」）→ 观众带走的是"工具"，认的是"能造词的人" → **观念类也能涨粉**。
- 证据：180 涨粉 **0.73%**（观念类最高）vs 同级情绪/共鸣观念（107/116/122/135/145）0.29%–0.68%。
- **涨粉预测从此"分型"写**：情绪/共鸣型 **0.3%–0.5%** · 命名概念型 **0.6%–0.8%**（旧口径"观念类一律 0.3%–0.5%"作废）。
- 落点：爆款公式要素表新增 ⭐「命名概念」行；「✅ 涨粉复核」新增「⑦ 命名概念测试」；「🦴 正文骨架」新增"命名概念"写法；「二十四」第 5 条改为分型。

### 📤 3. 转发层 ·「转发对象分型」（据 169 · 再验证 116）

- **转发对象决定"进不进朋友圈"**：**关心型**（我担心的人 · 自己人）→ **进朋友圈（10%+）**；**说服型**（反对的人）→ **只进私聊（3%–4%）**。
- 证据：116「还没把健康当回事的人」→ **11.18%🏆** · 169「总说自己检查没问题、状态却不对的人」→ **10.34%（全库第三）** vs 135「劝你别吃的那个人」→ 3.88%。
- 落点：爆款公式要素表新增 ⭐「转发对象分型」行；「✅ 转发复核」新增「⑤ 转发去向测试」（转发引擎区第 5 关）。

### ⚙️ 4. 规律校准 · 规律F「身份独占＝涨粉的**唯一**杠杆」→「**第一**杠杆」

## 🎓 四十六、一个月涨粉五万的大学生：三个「独家秘籍」（2026-10-08 认知整理）

> **张医生的体感**：这三条正好把 [[总控台/自媒体实操zfc|四十、老板IP 找选题]]（选题从哪来）、[[总控台/自媒体实操zfc|二十三、IP穿越周期]]（作品力）和 [[总控台/自媒体实操zfc|六、后端转化漏斗]]（怎么变现）串成一条完整链路——**她不是天赋异禀，是把常识执行到了位。**

### 🔁 1. 简单的事情重复做

- **原话**：别觉得每天写文案、拍视频是件简单的事。可当你真的做到第 100 遍，再回头对照第 1 遍——你会发现，第 1 遍和第 100 遍，真的是完全不一样的。
- **拆解**：短视频的门槛低到"谁都能拍"，真正拉开差距的从来不是技巧，是**同一个动作重复了多少遍**。第 1 遍靠冲动，第 100 遍沉淀下来的才是**手感、语感和镜头感**——这些无法速成，只能靠堆量堆出来。
- **落地**：给自己定一个"**先别优化、只管发布**"的冷启动期（如连续 30–100 条），把它当练基本功，而不是"等练好了再开始"。（呼应 [[总控台/自媒体实操zfc|十四、短视频表现力]]：表现力是练出来的，不是天生的）

### 📈 2. 火过的内容一定会再火

- **原话**：爆款永远都是爆款。一定要学会站在"巨人的肩膀上"去创作、去学习，别一上来就自己搞"原创"。

- **落地**：先在**对标**里找已经爆过的题，用你**自己的身份、场景和判断**把它重讲一遍——**抄结构，不抄内容**。（呼应 [[总控台/自媒体实操zfc|四十一、拆解陈晶883条视频]]：业务自己产生内容）

### 💰 3. 流量不等于变现

### 🧊 1. 现象：一人公司圈子，最近在聊一个词——「薄肌」

- **场景**：自由职业做满几年的人，聊的已经不是"怎么多接一单"，而是"**怎么活得久**"。他们的共同答案里，出现了一个词：**薄肌**。
- **反差**：别人囤算力、囤流量、囤知识库，这群人先囤**肌肉**——因为他们发现，前面那些，最后都要挂在一副身体上兑现。

### 🧮 2. 归因：为什么必须先囤身体（机制层）

- **账号、IP、Agent、知识库，全都挂在一副身体上**：熬三天写脚本，第四天嗓子哑、脑子空；连播一周，免疫力先垮。你以为是"灵感没了"，其实是**本金在透支**。
- **AI 时代的不确定性，反而让身体变成唯一确定的投入**：未来怎么走、机会在哪，你预知不了；但肌肉的多与少，是你能**提前开始、日日累积**的一个确定变量。
- **自由职业的"时间自由"是双刃剑**：时间多了，躺着也行、练也行——**正因为没人管你，才更需要一个自己的固定动作**（每天一次力量训练）。

### 🏷️ 3. 命名：「薄肌储蓄」——身体唯一能存下来、不贬值的资产

- **什么叫储蓄**：脂肪会掉、状态会起伏、精力会用完；**只有肌肉，是身体里能"存"下来、不看行情、不贬值的那部分**。
- **为什么叫"储蓄"而不是"锻炼"**：锻炼是一次性消费（办卡那一刻以为自己买了健康），储蓄是**每天往一个账户里放一点**——把力量训练当成给未来的自己转账。
- **关键区别**：身体不吃一次性付款（呼应配套朋友圈 [[B自媒体大脑/05-朋友圈创作/交付脚本库/PYQ-2026-09-28-运动这笔账]]）。存肌肉靠的是频率，不是强度。

### 🎯 4. 落点：一人公司生存公式

> **Agent ＋ 薄肌 ＋ 个人IP ＋ 自媒体 ＋ 睡眠 8 小时 ＝ 一人公司生存模式**

- **拆开看**：Agent 和外脑替你干活（效率），个人 IP + 自媒体替你获客（流量），**薄肌 + 睡眠 8 小时替你续命（续航）**——前三项决定你跑多快，后两项决定你能跑多远。
- **一句话**：未来你预知不了，但身体，是你唯一能**提前建仓的确定性**。

### 🚀 5. 落地到我们的三条

1. **把"每天一次力量训练"设成固定动作**：不办卡、不做复杂计划，今晚先做一组深蹲，把第一笔存进去。
2. **把睡眠 8 小时当 KPI**：它和力量训练是一对，缺一个另一个打对折——这是省不下来、也外包不出去的成本。
3. **把"囤身体"讲给伙伴听**：给伙伴看的不是养生，是**创业者怎么让自己在长跑里活得下来**——这是一人公司模式里最容易忽略、又最不能省的一环。

## 🌟 四十八、AI 未来时代，个人 IP 三步：找到自己 → 被看见 → 变成产品（2026-10-13 认知整理）

> 来源：张医生本人口述「真正 AI 未来时代，我认为最重要的几件事」整理（2026-10-13 · 讲团队/伙伴）
> **一句话**：AI 未来时代真正重要的就三件事——**先找到自己是谁，再被更多人看见，最后把过程变成产品**。自媒体也好、创业也好，本质上都是**真实的自己那股能量，被呈现出去、传递出去**的过程；技巧和套路遍地都是，只有真实的你，才是壁垒。

### 🧭 1. 第一步 · 找到自己是谁（IP 的底层 = 定位）

- **IP 的本质，是为了让自己被更多人看见**；而"被看见"的前提，是你先知道**自己是谁**。
- **每一段走过的历程，本身都是一幅作品**——关键不在经历多传奇，而在于你有没有**把这段历程构建成故事的能力**。
- **从哪里挖**：打开你**自己的产业 / 项目 / 产品**，去找那段**你真真实实走过、也真真实实做成过**的历程——痘痘调理好了、减掉几十斤脂肪、穿越过一段低谷又走到高光、为了家里人的健康走过一段路……这些都可以。
- **为什么这条最值钱**：因为它是你**真实走过来的**，也**真的做成过**——别人抄不走、复制不了。任何一段这样的历程，都能成为你 IP 里最亮的一个闪光点。**这就是 IP 定位真正要深挖的那个核心点。**

### 📣 2. 第二步 · 被更多人看见（传播 = 一切链接的基础）

- 核心点找到了，**IP 的底层就已经立住了**。接下来就是**大量地去传播、去分享**。
- 用**自媒体 + 社群 + 朋友圈全方位**把自己展示出来——用心地输出、用心地表达、用心地构建故事，把真实的那股能量，通过自媒体**爆发出去**。
- **逻辑链**：先表达、先输出 → 让更多人看见 → **被看见，你才"存在"** → 才对人产生吸引力 → **吸引别人，就是一切链接的基础**。
- 一句话：**不是等别人来找你，是先把真实的自己，送到更多人面前。**

### 📦 3. 第三步 · 把过程变成产品（产品思维）

- 当越来越多人看见你、被你吸引，就一定会有人**想成为你、想学习、想被交付**。
- 这时候用**产品思维**，把你走过的这段路、这套方法，变成**可交付的产品**。
- **好处**：一旦有了产品，**后期的辅助（成交 / 带人 / 复制）都会变得简单**。

### 🎯 4. 收口 · 自媒体与创业的本质

- 自媒体也好、创业也好，本质上就是一个**真实的自己、那股能量被呈现出去、传递出去**的过程——**其实没有多复杂**。
- 当我们借助**个人 IP 的打造**去放大这股能量时，**一切都会变简单**。
- **反面**：如果不重视这一点，天天去研究**技巧、套路**——这些东西**遍地都是**，既没有竞争力，也构不成真正的**壁垒**。

### 🚀 落地到我们的三条（团队口径）

1. **写下你做成过的那一件事**（一段真实历程），并把它写成一段能讲 3 分钟的**故事**——这是你 IP 的地基。
2. **把这段故事"说出来"**：发一条朋友圈 + 拍一条短视频，先让身边人看见。
3. **想清楚别人看完愿意为什么买单**（想成为你 / 想学 / 想要你的方案），哪怕先只是一个思路，也把它写成一个**产品雏形**。

## 🧠 五十、屁股决定脑袋：处境决定认知，认知锁死行动（2026-10-15 认知整理）

### 🧊 1. 现象：想做事的伙伴，一开口全是"可是"

- 创业？——"可是我没钱。"
- 转型？——"可是我要上班。"
- 搞自媒体？——"可是家里一堆事等着我。"

这三句话听起来都很**对**，对得让人无法反驳。但它们的"对"，全部对在**当下**，不在未来。

### 🧮 2. 归因：位置决定认知（机制层）

- **人是拿"屁股"决定"脑袋"的**——你坐在哪个位置，就只能看见那个位置的那点现实。
  - 坐在**月薪**那把椅子上，你算的是这个月够不够花 → 任何"先投入后回报"的事，在你眼里都是**赌**。
  - 坐在**打工**的位置上，你想的是别丢了这份稳定 → 任何"从零开始"的事，在你眼里都是**险**。
  - 坐在"**我没资源**"那个坑里 → 你看见的所有机会，都是**骗局**。
- 于是认知被当下的处境**锁死**：你不是在判断未来，你是在**给"不敢动"找理由**。
- 穷人思维最要命的地方：**不是没钱，是拿你现在的位置，去替五年后的你做决定。**

### 🏷️ 3. 命名：「屁股决定脑袋」＝穷人思维的开关

- 这是个俗语，好懂、好记、**可被指认**——新人卡点一说就中，比自己讲一堆道理有力。
- 命名一旦立住，它就变成了一个**可转发的词**：谈"位置锁死认知"太抽象，说"你这是屁股决定脑袋"，一句到位。

### 🎯 4. 破解：让"脑袋"先走到未来

1. **先定"去哪"**：想清楚 5 年后要成为谁——不问"我配不配"，只问"我要不要"。
2. **再倒推"这一步"**：从未来目标往回倒，找到今天能动的最小一步，而不是从今天的条件往前推"能不能行"。
3. **屁股可以还在原地，脑袋必须先到未来**：判断标准来自未来，不来自现状。
- **一句话**：困住一个人的从来不是处境，是他**只肯用处境去想事**。

### 🚀 5. 落地到我们的三条

1. **自己**：做重大决定前自查——"这个判断，是用未来的眼光下的，还是用现在的位置下的？"
2. **带伙伴**：新人卡在"我想做但我不行"，**先破认知，再教方法**——他不是没能力，是只用现在的位置想事。先帮他"看见去哪"，再谈怎么走。
3. **做内容**：三句"可是"是绝佳的**可指认靶子**，一句一句点破，收在判词上（已成 PYQ 认知暴击型一条 · 见交付脚本库）。

## 🧠 五十一、信息茧房：困住账号的不是天赋，是你看的世界太小（2026-10-15 认知整理）

### 🧊 1. 现象：做内容的人，手机刷得比谁都勤，刷到的却全是自己爱看的

- 观点一样的、圈子一样的、跟自己一样还没做起来的——刷一整天，世界越刷越小。
- 天天喊没灵感、没方向，其实不是没才华，是**从没去看过外面的世界**。
- 刷到不一样的观点，第一反应是划走、骂一句——于是"你的世界里，永远只有你对"。

### 🧮 2. 归因：茧房是"算法 + 圈子 + 选择性接收"合谋造出来的（机制层）

- **算法**：平台只喂你爱看的，你越爱看什么，就越只看到什么。
- **圈子**：你待的群、你去的大会、你关注的号，全是同一圈人——让你误以为"所有人都这样""赛道已饱和"。
- **选择性接收**：不一样的声音，你划走；于是所有证据都在印证你自己。
- 三者叠加 → 认知被**越锁越紧**。做内容的人最怕这个：**闭着眼睛开车**，不知道外面流行什么，也想不通别人凭啥火。

### 🏷️ 3. 命名：「信息茧房」＝你的天花板

- 一个**好记、可被指认**的词——"你不是没见识，是你的见识被锁在越来越小的圈子里"。
- 对做号的人，它等价于一句判词：**你看见的世界有多小，你的账号就有多小。**

### 🎯 4. 破解：看见 → 模仿 → 执行（三步破茧）

1. **看见**：放下你爱看的，去看你不看的——看爆款、看别的赛道、看评论区里真正的普通人。
2. **模仿**：不是抄内容，是**拆结构**——开头三秒怎么勾人、选题从哪来、结尾怎么收，拆开揉碎，换成自己的料。（对标：吕白《从零开始做内容》"70% 模仿爆款 × 换自己的词根"）
3. **执行**：发出去，让真实世界给反馈——没人看、被骂、跑不起来，都比闷在茧房里自我感觉良好强。
- **一句话**：信息茧房最狠的地方不是困住你，是让你以为你已经很懂了。

### 🚀 5. 落地到我们的三条

1. **自己**：每天雷打不动看几个"我"不服气的号，看它凭什么火——**把刷信息的时间，换成看世界的时间**。

## 🧭 五十二、四步找到属于你的人设：自我盘点 → 受众分析 → 差异化定位 → 标签组合（2026-10-16 课件整理）

> 📥 来源：`~/Downloads/四步定位.pptx`（《四步找到属于你的人设》课件 · 6 页）

### 🎯 1. 一句话

定位不是"想"出来的，是"盘点"出来的——从你**已经有**的东西里挖，不是从你**想要**的东西里造。

### 🔍 2. 第一步：自我盘点——挖掘你已经有的"人生资产"

- **身份/职业**：主业、副业、证书、学历……
- **技能/特长**：你会什么？
- **性格**：你是一个怎样的人？
- **兴趣**：你喜欢做什么？
- **要点**：盘的是**存量**，不是许愿增量。每个人都有可用的资产，只是从没被列出来过。

### 👥 3. 第二步：受众分析——找到你想对话的"那群人"

- **他们是谁？**（年龄、性别、城市、身份）
- **他们的痛点是什么？**（焦虑、困惑、需求、经济）
- **他们喜欢看什么？**（内容形式、风格、平台）
- **他们在哪里活跃？**（抖音、小红书、视频号、B站）
- **要点**：先有"人"，再有"账号"。定位的另一半不在你身上，在你要对话的那群人身上。

### 🏷️ 4. 第三步：差异化定位——找到你的"人设蓝海"

- **找对标**：列出 3 个你欣赏的同领域博主。
- **拆标签**：他们 = A + B + C…（把他们的记忆点拆开看）。
- **三问**：①我能提供什么他们没提供的价值？②我的个人经历有什么独特之处？③我能用什么不同的形式或风格来表达？
- **差异化公式**：**大众赛道 + 小众特长/视角 = 你的蓝海**。

### 🧩 5. 第四步：标签组合——创造你的"人设记忆点"

- **初级公式**：主业/专业 + 兴趣/特长 + 性格/风格 = 初级人设
- **升级公式**：（主业 + 兴趣）× 表现形式 = 高级人设
- **避坑**：标签**不超过 3 个**，且要真实、可持续、有关联。

### 📋 6. 人设定位画布（可直接给伙伴填）

1. **我是谁？**　职业/身份：____　技能/特长：____　性格/风格：____　兴趣/热爱：____
2. **我想吸引谁？**　年龄/身份：____　他们的核心需求/痛点：____________
3. **我的不同之处？**　我和同类博主最大的不同是：____________
4. **我的人设公式**：【____】+【____】+【____】= 我

### 🧠 7. 我的分析（与 vault 已有框架对照）

- **顺序不可颠倒**：先盘自己（一）→ 再定受众（二）→ 再找差异（三）→ 最后收口成公式（四）。倒过来先想标签，必然假大空。
- 本文 = 四十八「找到自己是谁」那一步的**具体操作法**（四十八讲"为什么"，本文讲"怎么做"）。
- "自我盘点"是**内锚**，"受众分析"是**外锚**——正对应四「身份定位：两个锚（最难的一环）」;第三、四步是让两锚**对撞出唯一性**。
- 与四十二「IP = 可识别的你」呼应：**公式存在的唯一目的，就是让"你"可识别**——三个标签即三个识别钩子。

### 🚀 8. 落地到我们的三条

1. **自己**：先填一遍画布——把"我是谁 / 我想吸引谁 / 我哪里不同 / 我的公式"写成一页纸，贴墙上，随时校准。
2. **带伙伴**：新人第一课就填这张画布。**先盘存量再谈定位**，避免一上来就"我要做个大号"的空想。
3. **做内容**：公式里的三个标签，直接决定你的**开头钩子**和**选题方向**——定位不清，选题必飘。

## 🧠 五十四、心力的本质是智慧：你不是没心力，是认知没到（2026-10-16 认知整理）

> 📥 来源：张医生口述（2026-10-16）

### 🎯 1. 一句话

心力不足，从来不是意志力的问题——是你对这件事的**认知还不够深**。摇摆的每一秒，都在偷偷交一笔"心力税"。

### 🧊 2. 现象：越想做事的人，越觉得"心力不够"

- 别人一句话，你就动摇；一次挫折，你就想撂挑子。
- 明明很想做成，可真到要扛的时候，力不从心。
- 于是去报疗愈、上修行、参加心力营——舒服两天，一遇到事又垮了。

### 🧮 3. 归因：摇摆背后是认知不够（机制层）

- 先做个思想实验：现在是 2026 年，让你回到 2016 年——你会买房吗？会买特斯拉的股票吗？
- 会。而且你**一点都不需要心力**——别人骂你傻逼你也不在乎，你只会嘴角微微一笑、留个背影，十年后让时间说话。
- 为什么不需要心力？因为你**笃定**：你看得见结果，所以既不需要"坚持"，也不需要"对抗"。
- 反过来：心力不足的人是**摇摆**的；摇摆是因为**不信**；不信是因为**看不透这件事的本质**。
- **摇摆本身，就是最大的能量消耗**——力气没花在做事上，全花在"要不要做、对不对、会不会输"的内耗里了。
- 所以：**所有的心力不足，本质上都是智慧不足、认知不足。**

### 🏷️ 4. 命名：「心力税」＝每一次摇摆都在交的税

- 你不是没力气，是你的力气在**左右摇摆**里漏光了。
- 命名成"心力税"：每一次动摇、每一次内耗，都在交一笔税——交得越多，真正能做事的力气越少。
- 认知到位的人不交这笔税：他只做一件事，且对这件事看得极清楚，心力自然够用。

### ⚔️ 5. 绕不开的一关：直面困难本身（而不是反复止痛）

- 光提升认知还不够——很多人"提升认知"的方式是**止痛**，不是**治病**。
- 市面上的疗愈、修行、心力营，大部分像**吃布洛芬**：当下很痛，疗愈一下立刻不痛了，但**治标不治本**。
- 所以它**上瘾**：疗愈一次好了，再出问题，再疗愈……反复疗愈、反复发作，因为根子从没解决。
- 真正的解法只有一个词：**直面困难本身**。合伙人伤害了你、员工背叛了你，反复疗愈没用——因为你**没有勇气去面对它、回忆它**，你太把自己的痛苦当痛苦了。

### 🎯 6. 两个心法：策略与结果分离 + 别把单次失败上升成评价

**（1）把结果和策略分开**（打德州扑克）：

- 你输了，不代表策略错了——可能对手完全不按章法乱打，偏偏运气逆天。
- 但拉长到打一千次、一万次，一定是老手赢。**策略，是让你多次赢的系统；单次的输赢，只是样本在随机碰撞里碰出的一个结果。**
- 闯红灯没被撞 ≠ 闯红灯是对的——**被撞不被撞，和策略对错没有关系。**
- 大部分人恰恰死在这一点：太在乎某一次的得失，一次输了就不想打了——**他们是拿结果当策略。**

**（2）别把单次失败，上升成对自己和对别人的评价**：

- 优秀的创始人会想：是不是我的**用人策略**有问题？我的**用人审美**有问题？
- 心力不足的创始人会想：我是不是不行？他是不是个混蛋？——**把一件具体的事，情绪化成了对人格的审判**，于是这事就永远过不去了。

### 🚀 7. 落地到我们的三条

1. **自己**：一旦想放弃，先别骂自己"没意志力"——问一句"我到底是累了，还是根本不信这件事？"不信，就去补认知，别硬扛。
2. **带伙伴**：伙伴卡在"知道该做、但就是做不动"，**先补认知，再谈坚持**——他不是执行力差，是对这件事看得还不够透、还不够相信。
3. **做内容**："心力税""反复疗愈＝吃布洛芬"是绝佳的**可指认靶子**，一句就中（已成 PYQ 认知暴击型一条 · 见交付脚本库）。

## 🎛️ 五十五、张医生内容工作台：打开 Obsidian 就是生产流水线（2026-10-19 自建插件）

## 🧱 五十六、成本坍塌 × 一人公司 × 两个大脑：AI 时代普通人上桌的完整逻辑（2026-10-20 录音整理）

> 📥 来源：2026-10-17 线下分享逐字稿（赖老师 · 张医生）
> 📄 完整笔记：[[A知识沉淀大脑/01-旧知识沉淀/04-短视频知识/自媒体研究/09-AI时代创业与应用·成本坍塌·一人公司·两个大脑|09 · 成本坍塌·一人公司·两个大脑]]

### 🎯 1. 一句话

不是谁更会做生意，是**成本结构塌了**；成本一塌，牌桌就换人——换成会用 AI 的那批。普通人上桌的姿势只有一个：**一个专业大脑 + 一个自媒体大脑 + 一堆 AI 员工**。

### 🧮 2. 成本坍塌：两头同时塌，才叫机会

**需求端——盘子没变小，只是换了地方：**

- 做到 4 万亿流水：京东 20 年 / 拼多多 8 年 / 抖音 5 年。
- 抖音电商 2025 年 GMV 预计 4.3 万亿（增速 >30%），淘宝天猫 8.3 万亿（增速 6%）——**增速差 5 倍**。
- 底层是注意力迁移：**"在刷视频的路上顺带把东西买了"**——需求在内容里产生，不在货架上产生。
- 判词：**需求端没有关门。**

**供给端——生产与获取流量的成本塌了：**

| 项 | 过去 | 现在 |
|:--|:--|:--|
| 1 分钟成片 | 5000–35000 元 | 约 80 元（会写提示词） |
| 一条广告周期 | 10–20 天 | 1–2 天 |
| 电商商拍 | 真人模特棚拍 | AI 模特，成本约 1/10 |
| 岗位结构 | 摄制组一堆人 | 编剧 + 资产生成师 + 抽卡师 + 后期 |

- **试错成本塌了，普通人才第一次有了"用很低的钱试一件正经事"的资格。**

### ⚖️ 3. 人被替代还是被重新定价

> **传媒人不是被替代了，是被重新定价了。**

- AI 打掉的是**执行**：拍摄、剪辑、特效、出片——最贵、最耗时、最耗人的那一段。
- AI 短期拿不走的是**判断**：导演、镜头语言、节奏、编剧——"什么能打动人"。
- 真实案例：特效导演被突然裁掉（N+1，老婆二胎、有房贷），靠自己的审美重新上岗——做主管，**管的不是员工，是 AI**（判断哪些生成结果合格）。
- 所以一句必须刻进去的话：**别跟 AI 比快，跟它比准。**准，就是判断力、审美、信任。

**一盆冷水**：86% 的创作者已在用 AI，但只有 4% 靠它年入 10 万美元以上；创作者账号 1.8 亿。**稀缺的从来不是内容，是判断力与信任。**

### 🏢 4. 一人公司：岗位没少，人员结构变了

- **一人公司 ≠ 一个人干所有活**，是"你 + 一堆 AI 员工"构成一家公司。
- 商业结构一点没变（营销 / 服务 / 交付 / 售后），变的是**谁坐在那个位置上**。
- 成本账（做短视频这一件事）：传统配置约 **4 万/月**（文案+拍摄+剪辑+操盘+客服）→ AI 配置约 **350–1200 元/月**。**差两个数量级。**
- 真正的杠杆不是"你多能干"，是"**能复制几个你**"：一个人最多服务 10 个客户，10 个你 × 10 个客户 = 100。

### 🧠 5. 两个大脑：一个管交付，一个管被看见

```
专业大脑（我拿什么交付）  ×  自媒体大脑（让谁来找我）
        ↓
   信息差 → 交付 → 收入 → 复制
```

- **大脑的分工**：人脑用来**判断、选择、审美**；存储与调用交给 AI。
  > **你是在用大脑记东西，还是在用大脑做判断？**
- **入库纪律**：**没过我脑的东西，不是我的。**先过脑再入库，否则知识库只是别人观点的堆积。
- **自媒体大脑必须版本化**：V1.0（7-14 空白起步）→ 46 个版本（10-15），爆款反喂 = 知识反哺。
  > **一条爆是概率，连续十条爆是逻辑。**逻辑可训练，所以可复制。
- **最实用的一句**：伙伴说"我还不专业，等我考完证再干"——**不用等，直接用大脑，在做中学。**（前提：大脑已被验证过。）

### 💰 6. 商业的本质：信息差 × 交付

- 校服 / 营养方案 / 短视频陪跑，内核是同一件事：**客户有问题 = 客户没有这个信息；你有、你交付，他付钱。**
- 产品、方案、陪跑、课程、社群——**壳不同，芯都是信息差**。
- AI 把信息门槛砍平了，但现场问"听过 vibe coding 吗"，零人举手；全球仍有数十亿人没用过 AI。
  > **信息差没有消失，只是换了入口：会不会用 AI 把它调出来、变成交付。**（同 [[A知识沉淀大脑/00-新知识入库/洞见卡/DJ-AI-019-AI把信息差推平了，但90%的人还没用上AI|DJ-AI-019]]）
- 顺带一个财务认知：**十倍增长比两倍增长容易**——两倍靠延长工时（会封顶），十倍靠换业务结构。别用 AI 优化旧流程，要用 AI 重写流程。

### 🎬 7. 平台是"场"，不是"渠道"

| 平台 | 隐喻 | 该怎么用 |
|:--|:--|:--|
| 抖音 | **夜总会** | 要刺激，专业知识挑战极大 → 大健康基本放弃 |
| 小红书 | **女生宿舍** | 搜索解决问题 → **做贴图**，标签做足，多号铺词 |
| 视频号 | **电影院** | 社交+认真看 → **主打**：人设、信任、开头黄金 3 秒、中长视频质量 |

- 视频号的钱投在**直播**，短视频靠内容质量与社交传播；风控最严，每条必须过质检。
- **与 [[A知识沉淀大脑/00-新知识入库/知识卡片/KC-视频-011-抖音视频号小红书三平台选择与分发逻辑|KC-视频-011]] 的关系**：那条讲机制（拼爆发/拼关系链/拼搜索），这条讲赛道取舍（大健康别碰抖音）。**机制决定形态，赛道决定取舍。**
- 越往后越反直觉的一条：**AI 越普及，真实越稀缺。**认真打磨的作品、真实的人设在升值。

### 🛠 8. 现场实操里的三条硬经验

1. **方案智能体**：先喂权威源（营养圣经 / DRIs / 临床药学 / 官方指南）锁死边界 → 再固化模板 → 客户丢一个病名就出完整方案。**价值不在快，在要点抓得准。**
2. **多模型分工**：共情型模型（豆包）出初稿，逻辑型模型（DeepSeek）当审稿人挑逻辑断点与数据断点，再回补。口播不能有断点，这一步省不得。
3. **上下文纪律**：**一件事一个新任务**。一个对话里连着问两件不相干的事，答案一定飘。

> 还有一层更底层的：**未来的竞争，是工作流与工作流的竞争。**你拿到的"一段提示词"，本质是别人跑通过的工作流。所以把自己的手艺做成流程，流程就是可交付、可复制、可售卖的产品。

### 🚀 9. 版本答案与落地三条

**版本答案**（没有一件依赖平台红利，全部靠自己可积累）：一个 agent · 一副肌肉 · 一个个人 IP · 一条自媒体 · 一个好觉。
其中"肌肉"不是健身口号，是**用一个可向往的结果反推一套生活习惯**（能练出腹肌的人，必然早睡、饮食干净、每周练力量）。

**落地到我们：**

1. **自己**：两个大脑分开维护、各自打版本号。混在一起会互相污染，也讲不清价值。
2. **带伙伴**：成本账（4 万 → 350 元）比"AI 很重要"有效十倍——**数字才是他能听懂的语言**。复制载体不是讲课，是两个大脑本身。
3. **做内容**：平台取舍按赛道收紧，大健康线**只打视频号 + 小红书贴图**，别三个都试——那正是"分配散"。

## 📡 五十八、短视频出圈 · 直播出单 · 私域留人：三层分工别搞混（2026-10-26 认知整理）

> 来源：外部口播整理（直播培训从业者 · 4 年个人 IP）｜全文拆解见 [[D直播工作台/直播方法论·短视频VS直播：哪种方式离钱最近]]
> **一句话**：**短视频是出圈的，直播是出单的；私域跟店域，才是用户的终身价值。**

# 58.1 核心判断（五条）

1. **个人 IP 行业里，最科学、安全、持续、合规的引流方式，就是直接开播**——流量要批量高效转化，绕不开直播这一环。
2. **短视频引流效率巨低**：简介、昵称、合集、弹窗，全是低效安慰。曾一条视频评论区 4000 条留言，真正加得上微信的损失三分之二——**人留完就忘了，不会回来看谁回复了他**。
3. **资料钩子勾来的是低端粉**：拿到资料那一刻，往往就是拉黑那一刻。K12 例外（家长反正都得买），企业培训／知识付费不例外（打工人要报销、无决策权、可有可无就不买）。
4. **短视频爆了不等于马上开播**，中间必须有**直播预约**做缓冲。
5. **直播间本质就三个字：试听课**。不是来讲干货的——教会了走，没教会也走。

# 58.2 三件"替代品"：为什么会被连割三遍

```
做矩阵 → 买数字人 → 用 AI 写钩子文案
      ↓ 挨个割一遍
心灰意冷：500 个粉丝、加了 5 个微信、全是白嫖资料的
```

- 底层心理：**很多人为了不开播，愿意做一切事情——除了开播。**
- 真相：难的不是开播，是把开播想难了。

# 58.3 直播预约＝电影票＝粉丝见面会

| 摆摊 | 粉丝见面会 |
|---|---|
| 硬在大街上凭自己本事拉客 | 先把人聚起来，等人来蹲你 |
| 开播对空气说话、坐冷板凳 | 开播时已有一批对你有好感的观众 |

- **电影票逻辑**：预告片（短视频）→ 买票（预约）→ 进场后有耐心。
- 预约的真正作用：**给自己的直播间，提前蓄一批意向观众。**

# 58.4 试听课：直播该给的是什么

| 行业 | 体验形态 | 升单路径 |
|---|---|---|
| 健身房 | 49 元私教体验 | 次卡 → 年卡 |
| 美容院 | 面诊／清洁 | 体验 → 大额卡 |
| 英语培训 | 公开课／试听 | 试听 → 20 节 → 50 节 |

- **陌生人的耐心只有 15 分钟**：不是让你两小时讲完一个知识点，那是上课，不是体验。
- 15 分钟内让他觉得值 → 买**次卡**（49／39 元）→ 到私域或到店**升年卡**。

# 58.5 海陆空三军：三层各干什么

| 环节 | 类比 | 任务 |
|---|---|---|
| 短视频 | 广告 | 拉新、出圈 |
| 直播间 | 大众点评 | 卖次卡、销售转化、出单 |
| 私域＋店域 | 会员体系 | 升单、复购、终身价值 |

- **成交是体系，不是单点**：广告 ＋ 促销 ＋ 销售政策 ＋ 体验续费升单 = 一套小连招。
- 只靠短视频一个动作就等客户上门，是异想天开；**有短视频，直播才如虎添翼**。

# 58.6 对张医生这套系统怎么用

- 现有漏斗（[[总控台/自媒体实操zfc|六、后端转化漏斗]]：短视频 → 直播卖 49 元课 → 陪跑 → 线下面授）**结构本来就对**，本文补的是每层的"性质"。
- **改口径**：直播不是"讲一节课"，是"上一节试听课"——每 15 分钟一个完整体验闭环，不搞两小时干货长跑。
- **加动作**：每条短视频挂**直播预约**，不做无预约硬播（机制见 [[D直播工作台/直播方法论·视频号短直联动]]）。
- **两条线的试听课**：营养线＝科普＋答疑体验；创业线＝方法＋路径体验；后端都回到营养素／陪跑营。
- **带伙伴时先拆心理门槛**：伙伴最容易掉进"矩阵＋钩子＋数字人"的坑，先把"开播"这一步迈过去。

- ❌ 「线下大课」→ 改「面授／面对面」

## 🧭 五十九、跟线上朋友讲大健康：一段完整的事业说明怎么讲（2026-11-02 沟通整理）

> 来源：与一位线上认识的朋友的语音沟通｜整理稿全文见 [[A知识沉淀大脑/01-旧知识沉淀/05-安利/05-安利业务/跟互联网朋友讲大健康-一场完整沟通整理]]
> **一句话**：**事业说明不是背话术，是三段递进——我为什么走这条路 → 这生意怎么做 → 你能不能做。**

# 59.1 五段结构（开口顺序不能乱）

1. **先回答"你一个医生为什么做这个"**：从"十年后跟今天不会有太大变化"讲起，这个画面让人恐怖；不抱怨医院、不贬低体制。关键句——**不是干不下去才走，是想清楚了才找第二条路**；前面七年副业不是闲着，是找路。
2. **再讲"我为什么走进大健康"**：顺序必须是 自己身体出问题 → 考营养师证 → 发现"医院治的是结果、营养管的是前端" → 自己先受益（鼻炎、免疫力）→ 才相信这个行业值得做。**先被改变，再做买卖**——这一段最抗质疑，因为是自己的体感，不是别人的案例。
3. **讲"这生意怎么做"**：两条线同时走。找顾客＝学（基础营养→临床营养→考证）→ 讲（朋友圈/社群/健康讲座/家庭聚会）→ 做方案 → **陪跑落地**；找合作伙伴＝分享为什么创业、为什么选这个平台、为什么选健康 → 同频的人来了解 → 他也兼职、也学、也找顾客再找伙伴。**方案＋陪跑才叫服务；团队是陪出来的，不是管出来的。**
4. **讲"为什么是这个"**：健康是刚需（人人需要，且我们抓的是慢病最前面的生活方式）／机会是刚需（裁员、焦虑的人缺一个不压本钱又能自己说了算的入口）／门槛低到亏得起。对我这种刚亏过钱的人，**"亏得起"比"赚得多"更打动人**。
5. **讲"我可以教你"**：自媒体不改变生意逻辑，**只放大半径**（过去只找身边人，天花板是你的圈子）。六步路径＝定位（商业定位→IP 定位）→ AI 选题文案 → 脚本 → 口播 → 剪辑 → 发布；然后一句收口——**"我就是线上做起来的，现在带的很多人也是线上做的。"**

# 59.2 对方最实的三个问题 + 我们的口径

| 对方问 | 我们的答 |
|---|---|
| 你收入多少 | 个人隐私，不细说。能说的是：2020 全职、六年、比医院好、往年薪百万这个目标靠近，团队里做得厉害的很多 |
| 你这个职位/身份怎么样 | 别拿我当标准。有人做到百万，也有人十年连主任都没做到。**每个人都是独立的，位置可以超越，但不会自动到手** |
| 我该跟谁学 | 大老师带不了零基础的人（层级差太远）；你现在需要**一个能一对一带你走完前几步的老师**；更要紧的是**跟一个团队走，别一个人摸索**；我们主线线上运作、没成本，可以先试 |

# 59.3 制度怎么讲才不翻车

- ✅ 讲**路径**：第一年一个市场、第三年三个市场、三个市场做稳进到制度里的高阶（团队通常讲的"中国股东"量级、年薪百万的目标线）。
- ❌ 不讲**结果**：不说"你三年也能年薪百万"。同一套制度，人是变量——**"师傅领进门，修行靠个人"这句话不能省**。
- 数字只做"制度测算"，不做收入承诺；对外内容里连"测算"都淡化成"制度里的路径"。

# 59.4 讲的时候最容易犯的三个错

1. **一上来讲制度和奖金**：对方还没信"健康是真的"，你已经在讲"钱是真的"，后面全在防你。
2. **把营养讲成治病**：慢病只能用"前端 / 生活方式 / 预防改善"，一句"能治"就把专业变成风险。
3. **讲成"你来跟我干"**：正确姿态是"你先看看这条路是不是你要的"——**他问才答，不问不追。**

# 59.5 落地到我们的三条

- 这条讲法可以直接拆成**创业线脚本骨架**：五段＝五条选题，尤其第 1 段"医生为什么做这个"就是**身份独占型**，正好接涨粉配比闸门的第 4 条；
- 新伙伴第一课就用这篇当**事业说明范本**：先让他对着镜子把五段讲完（不许看稿），再谈选题和拍摄——**讲不清说明没信，拍不稳**；
- 面对线上来的陌生人，顺序永远是**先"我的故事" → 再"路径" → 最后"机会"**，顺序一颠倒，后面全是解释。

> ⚠️ 对外红线：收入只讲目标与路径、不做承诺；身体改善一律标"个人体感，不构成诊疗建议"；不出现"包教包会／保证／无效退款"。

## 🧭 六十、做自己才是最大的杠杆：回归自身 → 找到价值点 → 放大分享（2026-11-02 分享 ＋ 11-03 一对一）

> 来源：十一月社群运营前的开场分享 ＋ 2026-11-03 与一位伙伴的一对一沟通（口播整理）｜核心是"我这两年最大的一个转变"
> **一句话**：**做得很吃力，是因为一直在向外求；做得简单又大，是因为回到了自己——找到你走过的这段路，把它放大、分享出去。**

# 60.1 症状：吃力，是因为一直在外面找

- 听了很多优秀的老师、台上嘉宾、付先生、全球访谈节目——**一直在找"他们到底厉害在哪里"**。
- 越找越累：追了一个周期，下一个周期跟不上；停不下来，停下来更慌。
- 问题不在方法不够多，而在——**向外求的人，最后忘了自己。**

# 60.2 归因：找不到自己的人，会活成一台机器

- 很多人上辈子（一辈子）被一份工作推着走：平平淡淡、没有起伏，**麻木**。
- 三个"不知道"：不知道自己为什么活着 / 不知道自己的价值在哪 / 不知道成长点在哪。
- 感受不到自己，日复一日重复，人就变成了机器。

# 60.3 转折：成功其实简单——找到自己，放大，分享

```
找到自己 → 把真正的价值点/能量无限放大 → 不断分享 → 影响一个人、再一个人 → 做得轻、做得热、做得大
```

- 台上那些做得大的人，共性是：**他们分享的，都是真正打动过自己的东西**——创业里、人生里让他有巨大力量的那一段。
- 再结合平台与业务呈现出来，所以他们的分享有能量，别人愿意听、愿意跟。
- 陈冠系统的愿景也是这一句：**让自己变得更好，做最好的自己。**

# 60.4 什么是"价值点"：你走过的那段路，就是人生最贵的资产

| 人 | 已经走完的路 | 这段路的性质 |
|---|---|---|
| 博 | 瘦了 40～50 斤，变得精致 | 拿得出手的作品 |
| 阿娟 | 痘痘最难看的那段，走过来了 | 独有的、能穿越周期的资产 |
| 婷老师 | 孩子那件事，走出来了 | 人生最重要的价值点 |
| 我（张医生） | 医院十年 → 奶茶店亏 40 万 → 爬起来 | 失败也是底牌 |

- 关键动作：**聚焦这一段 → 通过自媒体不断放大 → 它本身就是你最重要的产品。**
- 一辈子做成一件这样的事，就够了——**成功不需要很多件，需要一件拿得出手的。**

# 60.5 找不到怎么办：没有就创造

- 过去没有不代表不能有。**从当下开始打磨，让自己先发生这个变化。**
- 例：阿伟想让身材变好——现在开始，把这段"变"的过程走完、记录下来，**过程本身就是路径、就是内容。**
- 顺序永远是：先真的去做 → 才有路可讲 → 才有东西可放大。**不是先有内容，是先有变化。**

# 60.6 为什么"做自己"最难：两道坎

1. **找到自己的价值点**——大部分人根本没认真找过。
2. **愿意让自己成长**——知道还不够，要肯走那段不舒服的路。
- 卡住的具体原因：目标不明确 / 惰性 / **对"成功"的认知不够清晰**。
- 认知不清 → 就不会觉得"这件事对我很重要" → 就不会用心 → 就不会做到极致。

# 60.7 认知高度，决定执行强度（三个人的"为什么"）

| 表面的事 | 认知没到的人 | 认知到了的人 |
|---|---|---|
| 瘦下来 | 为了好看／为了健康 | **读懂了成功路径**：身体是承载一切的本钱 |
| 阿娟治脸 | 为了好看 | 这是**个人 IP、你的能量、能穿越周期的人生资产** |
| 阿伟练身材 | 一阵兴致 | **跟未来十年的价值点挂钩**，所以做到极致 |

- 同一件事，**给它挂上多大的意义，你就能下多大的功夫。**
- 这也是"心力不足＝认知不足"的又一层：不是不想干，是没看懂为什么要干。

# 60.8 拿得出手的东西 = 成功的入场券

- 人生总要有一个东西**拿得出手**：你这几年、甚至现在，有什么是能摆出来的？
- 没有这个东西，**凭什么成功？凭什么别人信你、跟你？**
- 两种都算：
  - **结果型**：瘦下来、脸好了、身材练出来了、把一件事做成了；
  - **经历型**：扛过困难、走过失败、从人生困境里爬起来——**这同样是底牌。**
- 我奶茶店亏 40 万那段路，就是我今天拿得出手的东西。**困难不是负债，是资产，关键在你如何用好它、跨过它。**

# 60.9 为什么不追热点：追外面追不赢，追自己能穿越周期

- 外面的世界变化太快：**你追一个周期，下个周期就跟不上；而且永远停不下来，越跑越累。**
- 追自己就不一样：**任何时代，你走过的这段路都拿得出手，永远不会过时。**
- 两条纪律：
  - **不跟任何人比**，要有自己的节奏感；
  - **不焦虑、不急**——读懂了这件事，人就稳了。

# 60.10 每天真正该干的那件事

- 每天都朝"那个有希望的自己"靠近一点：**跟自己死磕，走一段成长的路，感受自己在变好。**
- 这一件事，本身就让人开心、快乐、**不内耗**。
- 我很少内耗，就是因为每天想的都是"我要做自己"这一件事。
- 加上一个动作：**分享欲**——喜欢就发出去（朋友圈、自媒体），不是去"搞定"别人，而是你的状态和能量把同频的人吸过来。
- 结果：**伙伴、顾客都会变简单**——剩下的只是持续做事、加工作量。

# 60.11 落地到我们的三条

- **给每个伙伴先做一次"人生资产盘点"**：写下三件"我已经走完、别人没有"的路（结果型／经历型都算），选一件作为主价值点，其余做辅线选题；没有的，就从当下开始创造一个（定 90 天可见的变化）。
- **写内容前先问一句"这段路打动过我自己吗"**：不打动自己的，不写、不拍——**打动自己，才可能打动别人**（对应 [[总控台/自媒体实操zfc|四十八、找到自己 → 被看见 → 变成产品]]）。
- **所有"要不要做"的判断，先挂到未来十年**：这件事能不能成为我拿得出手的资产？能，就做到极致；不能，就别耗（对应 [[总控台/自媒体实操zfc|五十四、心力不足＝认知不足]]）。

# 60.12 一对一示范：价值点就藏在"你已经走完的那段路"里

- 一位伙伴：有想法、创业亏过钱、陷入低谷、焦虑压力大 → 后来重新找到机遇、在安利里走出来。**这段经历本身就是价值点。**
- 为什么？因为他身边的人同样迷茫、同样亏过、同样走弯路——他们缺的不是道理，是**一个已经走出来的人**。
- 董博士 92.5 公斤瘦了 40 多斤：他最有价值的不是理论，是**"我真把自己变过来了"**。别人信的不是道理，是结果。
- 价值点必须是真实走过的，包装出来的不叫价值点。**真实 → 放大 10 倍、100 倍 → 认同你的人来 → IP 立住。**
- IP 最怕的不是不专业，是**不真实**：真实才有信任度，有信任度价值点才清晰。

# 60.13 "走出去了"的定义：念头不在困难上

- 不是赚到钱、困难消失才叫走出去；是**不再执着于当下的困难，开始朝新的目标前进**。
- 路径：纠结当下 → 寻找新方向 → 朝新方向一点一点前进。**能量跟着念头走。**
- 能量起来 → 影响身边的人 → 影响更多人 → 钱是自然的结果。
- 当下焦虑、压力大，不要一蹶不振：**这段当下是你人生最重要的资产之一，能不能变成资产，取决于你怎么对待它。**

# 60.14 从价值点到商业定位：先找自己，再找赛道

- 越做越不像，是因为先找定位、找赛道、找人设，**唯独没找自己**。
- 商业定位第一步回到当下：**我是谁 / 我走过什么 / 我现在正在变成什么。**
- 你现在过得不好，不代表你没有价值——**你正在走的那段路，本身就是内容。**

# 60.15 起步路径：朋友圈 → 营养基本功 → 视频号 → 指导型 IP

1. **先从朋友圈开始**：记录真实改变，不喊口号、不卖货。
2. **同步补营养基本功**：知识、方案、沟通，一样一样跟上。
3. **视频号不着急**：不用等证书全到位才发；先记录，认知、证书、案例到位再系统讲。
4. **IP 自然长成**：我在学营养 → 我自己变好了 → 我能带别人变好 → **轻断食指导老师**这类有明确价值点的身份。
5. **不急着找人**：先把变化做出来，别人看到了自然会来问。**先做样板，再做老师。**

# 60.16 带人：影响而不是搞定（ABC 法则）

- 搞定别人很辛苦；影响别人靠两样：**你自己状态的变化** + **把你变成案例（C）**——你的身体和精气神就是活广告、就是样板。
- 有人来问，用 **ABC 法则**借力：**A = 我 · B = 你 · C = 朋友/顾客**。B 只需说一句"这是我老师张医生指导的，我帮你约他聊"，我沟通，B 在旁边学。
- 前提永远是：**先解决自己，让自己变化。** 自己不变，什么法则都是空转。

> - 做得很吃力，是因为一直在向外求——**向外求的人，最后忘了自己。**
> - 成功是简单的：**找到自己，把价值点放大，不断分享。**

## 🧭 六十一、成事之道：先立主线 → 挖价值点 → 做到极致 → 用时代的语言链接人（2026-11-06 录音整理）

> 来源：2026-11-06 腾讯元宝分享录音（35:43）→ [[A知识沉淀大脑/00-新知识入库/逐字稿-安利成事之道与业务路径梳理|逐字稿]]
> **一句话**：成事不复杂——先立一条主线当筛子，从真正做成过的事里挖出价值点，跟业态挂钩、选一个打磨到极致，再用这个时代的语言（自媒体）让别人看见；财富和认同，是价值被认可后的结果。

# 61.1 为什么先立主线：主线是筛子

- 成长路上最大的坑：一直在学，却说不清为什么学。
- 有主线 → 知道哪些该学、学了有没有用；没主线 → 东学西学、越学越乱、陷入迷茫。
- 学习前先过一道筛子：这件事服务我的主线吗？不服务，再火也先放下。

# 61.2 成事公式：个人价值 → 帮助他人 → 财富与认同

```
找到个人价值 → 用它帮到别人 → 社会认同 / 金钱回报
```

- 财富的本质是社会对你价值的认同；赚钱的背后，是你的价值对别人有帮助。
- 所有外在方法、技巧，都要回到两个问题：我的价值是什么？我怎么帮到别人？
- 做自媒体之前先答这两问——这本身就是商业定位课。

# 61.3 价值点怎么挖：只问"我过去做成过什么"

- 原则：回顾人生到现在，找自己真正做成的一件事——哪怕很不起眼。
- 结果型：腰突改善、把娃带到 985、减肥成功、把一件事做成。
- 经历型：从迷茫焦虑里走出来、创业亏钱又爬起来、把几个孩子带大。
- 标准：要"拿得出手"，别人才信你对他有帮助。
- 两步：① 先尽量列出来；② 再筛出跟当下业态挂得上钩的。

# 61.4 选一个，做到极致

- 不是每件做成的事都要用上；做安利、做自媒体，只选跟业态有关联的。
- 选一个，聚焦打磨，做到极致——成功的人都是把某一件做到极致。
- 粗糙就没有突出："减了 20 斤"遍地都是，凭什么成功的是你？
- 极致＝能被指认的结果：做减肥就练出腹肌马甲线；做营养就把方案讲到客户听得懂、愿意试。
- **赢一次，赢一辈子**；做成一件极致的事，你自己就是广告。

# 61.5 链接人：用这个时代的语言

- 普通人没有资源，链接人的办法是——让更多人看见你。
- 每个时代有每个时代的语言和工具；当下的语言就是自媒体。
- 不懂自媒体＝不会用这个时代的语言，别人听不到你的价值。
- 自媒体不是随便拍拍：表达、打光、拍摄、选题，都要研究到极致——这些学习都聚焦在主线上。
- 所以学习效率高，不是学得多，是学的都冲着同一个点去。

# 61.6 认知高度，决定执行强度

- 练马甲线只为好看，大概率练不出来——动力不够。
- 上升到人生层次：每一斤、每一块腹肌都在打造人生资产 → 会坚持，甚至急迫。
- 认知不到位 → 不觉得重要 → 不会认真做 → 做不到极致。
- 这又是"心力不足＝认知不足"的一层（接 [[总控台/自媒体实操zfc|五十四、心力的本质是智慧]]）。

# 61.7 落地到我们的三条

- **给自己和每个伙伴做一次"主线确认"**：这个阶段只做成一件事，写下来，贴在每天看得到的地方。
- **做一次"人生资产盘点"**：列 3 件已经做成、拿得出手的事，筛出 1 件跟业态挂钩的主价值点（接 [[总控台/自媒体实操zfc|六十、做自己才是最大的杠杆]] 60.11）。
- **所有学习先过筛子**：不能服务主线的课、工具、项目，先不加。

> 📼 金句收藏
> - 先立主线，学习才不是堆料；没有主线，学得越多越乱。
> - 财富是社会对你价值的认同——你帮到多少人，才配得上多少回报。
> - 你过去做成的那件事，就是你能拿出手的价值点。
> - 不做到极致，你和普通人就没有区别。
> - 赢一次，赢一辈子；做成一件极致的事，你自己就是广告。
> - 不懂自媒体，等于不会说这个时代的语言。
> - 认知的高度，决定你下多大的功夫。

## 🧭 六十二、短视频工业化生产：选题 → 脚本 → 交付 → 运营（2026-11-09 认知整理）

### 🎯 1. 一句话

**爆款不靠灵感，靠流程——用理性的流程，包装感性的内容。**

### 🧊 2. 现象：很多人不是不会拍，是每次都从零开始

同一个账号，这条爆了，下一条又回到原点。问他怎么选的主题，说"刷到的"；问脚本怎么写的，说"想到哪写到哪"；问什么时候发，说"剪完就发"。看起来很努力，其实每一次都在重新掷骰子。

### 🧮 3. 归因：三个错，四个环节没标准化

**三个错**：
- **心态错**：一上来就想快速变现。自媒体是复利游戏，前期像种树，不能天天挖开土看根。
- **方向错**：什么火发什么，最后谁也没记住你。没有定位，算法贴不上标签。
- **方法错**：把创作等同于"拍视频、写笔记"。表层是形式，内核是价值的持续交付。

**四个环节没标准化**：选题靠刷、脚本靠感觉、交付靠运气、运营靠心情。

### 🏷️ 4. 命名：「四标准化」＝ 选题 / 脚本 / 交付 / 运营

| 环节 | 标准化动作 | 关键指标 |
|---|---|---|
| **选题** | 公式＝受众面广＋借势＋价值＋情绪；对标拆三遍（爆点 / 算法标签 / 高赞评论）；70% 复制＋30% 随机 | 点击率 |
| **脚本** | 黄金三秒（冲突 / 替代结论）；中段埋 2–5 个评论点；模板＝否定＋确定＋运算＋举例＋建议 | 评论率、转发率 |
| **交付** | 看镜头上方圆点不看屏幕；五点布光；快门＝帧率两倍倒数；低 ISO；锁白平衡；外置麦 | 关注率、信任度 |
| **运营** | 饭前睡前定时发；地域内容加定位；神评论引导；翻牌回复；老视频点赞保温 | 完播率、转化率 |

> **一句话记住**：起号四步法——选题定点击、脚本定互动、交付定信任、运营定破圈。

### 🧭 5. 为什么是现在：三条判断

1. **自媒体不是风口，是规则改了。** 分发权从机构和平台，交回给每个普通人。风会停，规则不会退回去。
2. **机会一直在，但大多数人熬不到结果。** 门没关，关掉的是心态——一急，动作就变形。
3. **平台奖励的不是爆发，是稳定。** 我停更过两周，两个比我晚起步一个多月的人，涨得比我快。

### 🎯 6. 落地到我们的三条

1. **建一张"对标拆三遍"表**：每周固定拆 3 条同领域爆款，只记三样——爆点、算法标签、高赞评论诱因。
2. **把脚本变成填空**：黄金三秒 + 中段埋点 + 结尾三选一（引导 / 共鸣 / 悬疑），不再每次从白纸开始。
3. **运营做成 30 分钟 SOP**：早上拆 1 条、中午写 1 条、晚上发 1 条 + 回评论 + 给 1 条老视频保温。

### 📼 7. 金句收藏

- 一条精品是运气，十条合格才是策略。
- 平台奖励的不是爆发，是稳定。
- 自媒体不是风口，是规则改了。
- 做内容不是拍视频，是价值的持续交付。
- 你不需要完美，但需要真实且精准。
- 越不功利，路反而越顺。
- 自媒体是人生杠杆，不是快钱工具。
